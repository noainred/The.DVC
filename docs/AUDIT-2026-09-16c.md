# 보안 감사 — 외부 입력 → 장비 접속·명령 경로 (v2.537, 2026-09-16)

3차. 1차(v2.535)는 자격증명·비밀 추적, 2차(v2.536)는 인증·인가 게이트. 이번에는 **사용자·관리자가 넣은
값(host·URL·명령 인자)이 SSH 명령·HTTP 접속으로 흘러가는 지점**을 봤다.

**결과: critical 0 · high 0 · medium 2 · low 2 — 4건 모두 수정.** 명령 주입 축은 결함 0(전부 준수).

## [medium] DNS 리바인딩 차단 훅이 빠진 dispatcher 가 **9개** 있었다

| | |
|---|---|
| 위치 | `vcenter/restClient.js`(SOAP·REST 공용) · `nsx/client.js` · `idrac/redfish.js` · `idrac/ome.js` · `storage/collectors/restCommon.js`(Unity·PowerStore·PowerMax) · `storage/collectors/isilon.js` · `sanswitch/collectors/fosRest.js` · `svcmon/checker.js` · `rma/testRunner.js` |
| 사실 | v2.506 은 `lookup: ssrfLookup` 훅(접속 순간 해석 IP 를 검사 — TOCTOU 창 0)을 **11곳**에 배선하고 그 11곳을 테스트로 고정했다. 그런데 `new Agent(` 를 **전수**로 뽑으니 훅 없는 dispatcher 가 9개 더 있었다. 전부 **관리자·운영자가 등록한 host 로 자격증명(Basic/Digest/세션)을 싣고** 접속하는 경로다. |
| 정직 기록 | 손 grep 은 **8개**로 셌다. 9번째(`rma/testRunner.js` — `await import('undici')` 로 한 줄 안에 만든다)는 **회귀 테스트의 전수 스윕이 잡았다**. 목록 방식(v2.506)이 왜 재발하는지의 증거다. |
| 영향 | 등록된 이름의 DNS 를 쥔 쪽이 검사 뒤 해석을 사설/루프백으로 바꾸면 그 장비의 자격증명이 그 주소로 간다 — v2.506 이 horizon 등 11곳에서 막은 것과 같은 위협. `idrac/ome.js` 는 v2.506 문서가 **명시적으로 경고한 형태**(`resilientFetch` 에 자기 dispatcher 를 넘겨 wanAgent 의 lookup 이 통째로 사라지는 경우)였다. |

**조치** — 9곳 전부 훅을 붙였다. 삼항으로 갈리는 두 곳(`nsx`·`vcenter`)은 `withSsrfLookup()` 으로 **삼항 바깥**을 감싸 검증 ON/OFF 배포 어느 쪽에서도 빠지지 않게 했다. RMA 러너는 insecure 여부와 무관하게 훅 dispatcher 를 쓰고, undici 를 못 부르는 환경의 전역 fetch 폴백은 그대로 뒀다(그 사실을 주석이 말한다).

**실증** — `vcDispatcher` 로 `https://localhost:1/` 를 부르면 `ECONNREFUSED` 가 아니라 **`ESSRFBLOCKED`(루프백 차단)** 로 끝난다(아래 검증 표). 소스에 '붙어 있다' 가 아니라 소켓이 열리기 전에 막힌다는 뜻이다.

### ⚠ 운영 행동 변화(고지)
`localhost` 처럼 **이름이 루프백으로 해석되는** 대상은 이제 svcmon http 점검·RMA url 점검·vCenter/NSX/iDRAC/스토리지 접속 전부에서 차단된다. 엣지 자기 자신의 서비스를 `http://localhost:포트` 로 점검하던 곳이 있으면 `http://127.0.0.1:포트` 로 바꾸거나 그 엣지에 `SSRF_ALLOW_LOOPBACK=true` 를 준다. **IP 리터럴(127.0.0.1)은 lookup 이 불리지 않아 예전과 같이 통과한다** — v2.506 문서가 적어 둔 한계이고, 그래서 아래 [low] 의 정적 필터가 따로 필요하다.

## [medium] iDRAC·NSX 등록부가 host 를 **형식만** 보고 받았다

| | |
|---|---|
| 위치 | `idrac/registry.js normalize`(단건·수정·CSV import·`bulkAddByIps`·`registerScanned` 전부 이 함수를 지난다 — 확인함) · `nsx/registry.js normalize` |
| 사실 | storage/sanswitch/pdu 등록부는 v2.313 부터 `ssrfBlockReason` 으로 루프백·링크로컬·우회표기를 거부하는데, iDRAC 은 `https://` 를 붙여 주기만 했고 NSX 는 `https?://` 형식만 봤다. 폴러가 그 host 로 Redfish 자격증명·NSX 계정을 보낸다 — **등록이 곧 접속**이다. |
| 영향 | 관리자 전용 경로라 제3자 진입은 없다. 그러나 같은 저장소가 '외부 입력 host 를 네트워크로 찌르므로 ssrfBlockReason 통과 필수' 를 불변조건으로 두고 있고 세 등록부는 지키는데 두 곳은 아니었다 — 게이팅 비대칭. |
| 조치 | 두 `normalize` 에 `ssrfBlockReason` 추가. 실측: `127.0.0.1` · `https://169.254.169.254` 거부, `10.10.10.10` 통과, `bulkAddByIps('127.0.0.1, 10.10.10.11')` → added 1 · skipped 1(사유 루프백). 기존 저장 항목은 재검증하지 않는다(수정 시점에 걸린다). |

## [low] bmstor(SSH)·proxyHost 도 같은 규칙

`bmstor/registry.js bmServerInputIssue` 는 셸 메타문자만 막았고, `proxy/registry.js` 는 `proxyHost` 를 검사 없이 복사했다(SSH 게이트웨이가 다이얼하는 주소). 각각 `ssrfBlockReason`/`ipBlockReason` 추가. `PUT /remote/config` 는 throw 를 500 으로 흘리지 않고 **400 + reason** 으로 돌려준다(사용자가 무엇을 고칠지 알아야 한다).

## [low] iDRAC 스캐너가 차단 대역 IP 를 그대로 찔렀다

`idrac/scan.js` 는 `expandIpList` 결과를 그대로 `probeIdrac` 했다. lookup 훅은 IP 리터럴에 불리지 않으므로 `127.0.0.0/24` 같은 대역은 **정적으로** 걸러야 한다. 걸렀으면 말한다 — `blocked`·`blockedIps`(상한 200)·`blockedTruncated` 를 돌려주고, 로컬 스캔 `lastRun`·위임 결과 기록·스캔 작업 이벤트(`차단 대역이라 스캔하지 않은 IP N개`)·'최근 결과' 문구(`차단대역 제외 N`)까지 이어진다. 실측: `127.0.0.1-3` → `blocked:3 · scanned:0`, probe 0회(400ms 안에 반환).

## 정보 — 고치지 않았고 그 이유

- **`execAnswered` 의 `certAccept` 규칙**(`proxy/sshExec.js`): `Please input your selection[^\n]*\s*$` 이 꼬리에 오면 `1` 을 답한다. 선택지 블록 없이도 답하는 넓은 형태인데, 사용자 실측에서 프롬프트와 첫 데이터가 **같은 줄**에 붙어 와서 좁히면 실장비에서 멈춘다(v2.526 기록). uemcli 의 다른 선택 프롬프트가 있는지 **확인하지 못했다**(문서 차단). 이 규칙은 `unitySsh.js` 의 **조회(show) 명령**에만 붙고 `1` 은 '이 세션만 허용' 이라 오답의 피해가 없다 — 그래서 두었다. 파괴적 명령에 이 규칙을 붙이지 말 것.

## 보지 않은 것 (정직 기록)

- 실장비·실제 엣지에서 확인하지 못했다. 훅 발화 실증은 이 환경의 `localhost` 해석으로만 했다.
- 이번 축은 '어디로 접속하는가' 다. 접속 **뒤** 응답 본문을 어떻게 믿는가(출력 파싱의 인젝션 — 예: 장비 출력의 풀 이름이 다음 명령에 들어가는지)는 grep 으로 훑어 **보간 지점 0건**을 확인했지만 파서 단위로 읽지는 않았다.
- `rma/testRunner.js` 는 엣지에서 돈다 — 엣지 패키지가 undici 를 갖는지에 따라 폴백(전역 fetch, 훅 없음)이 남을 수 있다. 폴백 사실은 코드가 밝힌다.
