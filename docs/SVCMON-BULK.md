# 성능점검 — CSV 가져오기 / 내보내기

성능점검(svcmon) 대상과 점검 항목을 CSV 로 한꺼번에 등록하거나 현재 목록을 내려받는 방법입니다.
화면 위치는 **특수 기능 → ⚙️ 성능점검 설정 → 가져오기·내보내기**.

- 점검 유형별 상세: [SVCMON-TESTS.md](SVCMON-TESTS.md)
- 아키텍처·용량 산정: [SVCMON-ARCHITECTURE.md](SVCMON-ARCHITECTURE.md)

---

## 1. 먼저 샘플을 받으세요

`⤓ 샘플 CSV` 버튼이 **현재 버전의 스키마에서 생성한** 파일을 내려줍니다(문서에 박아 둔 상수가
아니라 코드에서 만들기 때문에 컬럼이 추가돼도 샘플이 낡지 않습니다).

샘플에는 6가지 예시가 들어 있습니다 — Linux 서버(점검 4개), 같은 폴더의 두 번째 서버,
웹 서비스(HTTP·인증서·도메인 만료), DNS 서버, 네트워크 장비(경로 추적, 중지 상태),
그리고 **점검 없이 대상만 등록하는 행**.

## 2. 행 레이아웃 — 점검 1건이 1행

한 대상에 점검이 여러 개면 **앞 5열(kind·path·target_name·host·target_enabled)을 반복**해서
씁니다. 가져올 때 `(kind, path, 대상 이름)` 이 같은 행들을 하나의 대상으로 묶습니다.

```csv
kind,path,target_name,host,target_enabled,test_name,type,interval_sec,test_enabled,port,...
infra,A.Infra\OC2\워커노드,lesasbpdp01,10.20.30.41,true,도달성,ping,120,true,,...
infra,A.Infra\OC2\워커노드,lesasbpdp01,10.20.30.41,true,워커 API,tcp,120,true,8080,...
infra,A.Infra\OC2\워커노드,lesasbpdp02,10.20.30.42,true,도달성,ping,120,true,,...
```
위 3행은 **대상 2개**(lesasbpdp01 에 점검 2개, lesasbpdp02 에 점검 1개)가 됩니다.

- `test_name` 이 빈 행 = **점검 없는 대상**(대상만 등록).
- 같은 대상을 가리키는 행들이 서로 다른 `host` 를 적으면 **오류**입니다 — 어느 쪽이 맞는지
  시스템이 판단할 수 없기 때문에 추측하지 않습니다.
- `path` 의 구분자는 역슬래시 `\` 입니다(최대 10단계, 세그먼트당 60자). 경로에 없는 폴더는
  자동으로 만들어집니다.

## 3. 컬럼 (25개)

| 컬럼 | 뜻 | 구분 | 필수 | 값 | 해당 유형 |
|---|---|---|---|---|---|
| `kind` | 구분 | 대상 | **필수** | `infra` · `service` | 공통 |
| `path` | 트리 경로 | 대상 | **필수** | 문자 620자 이내 | 공통 |
| `target_name` | 대상 이름 | 대상 | **필수** | 문자 120자 이내 | 공통 |
| `host` | 호스트/IP | 대상 | **필수** | 문자 253자 이내 | 공통 |
| `target_enabled` | 사용 | 대상 |  | `1/true/yes/y/on/예` = 참 · `0/false/no/n/off/아니오` = 거짓 | 공통 |
| `test_name` | 점검 이름 | 점검 |  | 문자 80자 이내 | 공통 |
| `type` | 유형 | 점검 |  | `ping` · `trace` · `tcp` · `udp` · `http` · `soap` · `dns` · `cert` · `ntp` · `smtp` · `pop3` · `imap` · `ssh` · `ldap` · `domain` | 공통 |
| `interval_sec` | 주기(초) | 점검 |  | 10~86400 (기본 **60**) | 공통 |
| `test_enabled` | 사용 | 점검 |  | `1/true/yes/y/on/예` = 참 · `0/false/no/n/off/아니오` = 거짓 | 공통 |
| `port` | 포트 | 점검 | `tcp`/`udp` 에서 필수 | 1~65535 (비우면 유형 기본 포트) | 공통 |
| `url` | URL | 점검 | `http`/`soap` 에서 필수 | 문자 500자 이내 | `http` `soap` |
| `keyword` | 포함 문자열 | 점검 |  | 문자 200자 이내 | `http` `soap` `smtp` `pop3` `imap` `ssh` |
| `expect_status` | 기대 상태코드 | 점검 |  | 100~599 (비우면 미지정) | `http` `soap` |
| `insecure` | 자체서명 허용 | 점검 |  | `1/true/yes/y/on/예` = 참 · `0/false/no/n/off/아니오` = 거짓 | `http` `soap` |
| `record` | 조회 이름 | 점검 |  | 문자 253자 이내 | `dns` `domain` |
| `server` | 질의 서버 | 점검 |  | 문자 253자 이내 | `dns` `ntp` |
| `expect` | 기대 결과 | 점검 |  | 문자 64자 이내 | `dns` |
| `payload` | 보낼 페이로드 | 점검 |  | 문자 200자 이내 | `udp` |
| `send` | 연결 후 보낼 명령 | 점검 |  | 문자 200자 이내 | `smtp` `pop3` `imap` `ssh` |
| `body` | 요청 본문(XML) | 점검 |  | 문자 4000자 이내 | `soap` |
| `soap_action` | SOAPAction | 점검 |  | 문자 200자 이내 | `soap` |
| `warn_days` | 경고 D-일 | 점검 |  | 1~365 (기본: cert 30 · domain 60) | `cert` `domain` |
| `warn_ms` | 경고 임계(ms) | 점검 |  | 1~600000 (비우면 미지정) | `http` `soap` `ntp` |
| `bad_ms` | 실패 임계(ms) | 점검 |  | 1~600000 (비우면 미지정) | `ntp` |
| `max_hops` | 최대 홉 | 점검 |  | 1~64 (비우면 미지정) | `trace` |

유형 기본 포트: `smtp`=25 · `pop3`=110 · `imap`=143 · `ssh`=22 · `ldap`=389 · `cert`=443 · `domain`=43 · `ntp`=123 · `dns`=53

### 없는 컬럼과 그 이유

| 컬럼 | 왜 없는가 |
|---|---|
| `id` | 가져오기는 **항상 새 항목으로 등록**합니다. 내보낸 id 를 다시 넣어도 그 항목을 갱신하지 않으므로, 컬럼을 두면 "왕복했는데 다른 항목이 생겼다"는 오해만 만듭니다. |
| `order` | 표시 순서는 배열 순서 자체입니다. 정렬용 숫자 컬럼을 두면 빈 칸이 전부 같은 값이 되어 수동 정렬이 무너집니다. |
| `batch` | 서버가 등록할 때 발급하는 태그입니다(롤백의 근거). 사용자 입력으로 받으면 남의 배치에 태그를 붙일 수 있습니다. |

### 빈 칸은 '기본값'입니다 — 최솟값이 아닙니다

이 점이 가장 자주 오해되는 부분이라 명시합니다. 값을 비워 두면 그 필드의 **기본값**이 적용되거나
**미지정**으로 남습니다. 하한으로 바뀌지 않습니다.

| 비워 두면 | 결과 |
|---|---|
| `interval_sec` | 60초 (10초가 아님) |
| `expect_status` | 미지정 — 500 미만을 정상으로 봄 (100 이 아님) |
| `warn_ms` / `bad_ms` / `max_hops` | 미지정 (1 이 아님) |
| `warn_days` | cert 30일 / domain 60일 |
| `insecure` | 거짓 = TLS 인증서 검증 **함** |
| `port` | 유형 기본 포트 |

> v2.242.0 이전에는 빈 칸이 하한으로 클램프되어 `expect_status=100`(정상 200 응답이 영구 실패),
> `interval_sec=10`(기본의 6배 부하)이 오류 없이 등록됐습니다. 지금은 위 표대로 동작합니다.

## 4. 엑셀에서 열 때

- 내보낸 파일은 **UTF-8 BOM** 이라 엑셀에서 바로 열립니다(한글이 깨지지 않습니다).
- `= + - @` 로 시작하는 값 앞에는 작은따옴표가 붙습니다(엑셀 수식 실행 방지). 가져오기가 그
  따옴표를 되돌리므로 **내보내기 → 가져오기를 반복해도 값이 자라지 않습니다**.
- 쉼표·따옴표·줄바꿈이 든 값은 따옴표로 감싸집니다(RFC 4180).
- 대소문자만 다른 `type`·`kind`(예: `TCP`, `Service`)는 정규화해 받습니다. 지원하지 않는
  유형(`disk` 등)은 **조용히 ping 으로 바뀌지 않고 오류**입니다.

## 5. 가져오기 절차

1. **파일 선택** — 또는 '파일 대신 붙여넣기' 로 내용을 직접 붙입니다.
2. **미리보기** — 저장하지 않고 판정만 합니다. 등록/건너뜀/오류 수, 신규 폴더·점검 수,
   상한 잔여, 용량 판정, 표본(앞 20 + 끝 5 + 건너뜀 일부)을 보여줍니다.
3. **등록** — 오류가 0건이고 등록할 대상이 1개 이상일 때만 눌릴 수 있습니다.

### 전부 성공 또는 전부 취소

오류가 **1건이라도** 있으면 아무것도 저장되지 않습니다. '오류는 무시하고 나머지만 등록'하는
선택지는 두지 않았습니다 — 부분 등록 상태가 가장 추적하기 어렵고, 어디까지 들어갔는지
확인하려면 결국 전체를 다시 비교해야 합니다.

이미 있는 대상(`구분 + 경로 + 이름` 이 같은 것)은 **건너뜁니다**. 같은 파일을 두 번 가져와도
대상이 늘어나지 않습니다.

### 오류 행 번호는 CSV 파일의 줄 번호입니다

헤더가 1행입니다. 미리보기의 `#` 열과 오류 목록의 행 번호는 모두 **원본 파일의 줄 번호**이므로
엑셀에서 그 줄로 바로 이동할 수 있습니다.

### 알 수 없는 컬럼은 보고합니다

헤더에 스키마에 없는 컬럼(`hostname` 같은 오타)이 있으면 무시하되 **미리보기에 그 목록을
표시**합니다. 조용히 버리면 "값을 넣었는데 반영이 안 된다"는 상황을 진단할 수 없습니다.

## 6. 한 번에 얼마나

| 항목 | 상한 | 초과하면 |
|---|---|---|
| 1회 가져오기 대상 수 | 2,000 | 오류(잘라내지 않음) |
| 1회 CSV 행 수 | 2,001(헤더 포함) | 오류 |
| 한 셀 | 4,000자 | 오류 |
| 전체 대상 | 20,000 | 오류 1건으로 사전 거부 |
| 전체 점검 | 200,000 | 동일 |
| 폴더 | 5,000 | 동일 |
| 대상당 점검 | 200 | 동일 |

상한을 넘으면 **행마다 오류를 만들지 않고 1건으로** 보고합니다(2,000행이면 응답이 수백 KB 가
됩니다).

## 7. 용량 판정 — 등록은 되는데 주기가 안 맞는 경우

미리보기가 "이 규모를 폴러가 소화할 수 있는지"를 함께 계산합니다.

```
초당 필요 처리량 = 활성 점검 수 ÷ 평균 주기(초)
초당 가능 처리량 ≈ 워커 수 × 62        (실측 4워커 249/s)
ping·trace 가능  ≈ 워커 수 × 16        (프로세스를 띄우므로 별도 상한)
틱 천장          = SVCMON_MAX_PER_TICK ÷ 틱 간격 = 4000 ÷ 5초 = 800/s
```

| 판정 | 조건 | 동작 |
|---|---|---|
| ⛔ 처리 불가 | 필요 > 틱 천장(800/s) | **등록 거부**. 어떤 튜닝으로도 지정한 주기를 지킬 수 없고, 화면은 '주기 60초'라고 표시하는데 실제 주기가 조용히 늘어납니다 |
| ⚠ 주의 | 필요 > 추정 가능, 또는 ping 필요 > ping 가능 | 등록은 되지만 권장 주기·워커 수를 안내 |
| ✔ 여유 | 그 외 | — |

ping 을 소켓형 기준으로만 계산하면 ping 위주 등록이 통과해 버리므로 **별도로** 계산합니다.
계산에 쓰는 상수는 [SVCMON-ARCHITECTURE.md](SVCMON-ARCHITECTURE.md) §3 실측값이며 워커 수는
서버의 실제 설정값(`SVCMON_WORKERS`)을 씁니다.

로그량도 함께 알립니다(`초당 처리량 × 86400 × 98B`). 예: 250/s → 약 2.0 GB/일.

## 8. 내보내기

| 옵션 | 설명 |
|---|---|
| 구분 | 전체 / 인프라만 / 서비스만 |
| 경로 | 그 경로와 하위만(예: `A.Infra\OC2`) |
| 점검 항목 포함 | 끄면 대상 목록만(1대상=1행) |

- 유형과 무관한 컬럼은 **빈 칸**으로 나갑니다(ping 행의 `warn_days` 등). 의미 없는 기본값을
  채워 내보내면 사용자가 그것을 설정값으로 오해합니다.
- 대량 내보내기는 8,000줄 단위로 흘려보냅니다(30MB 규모를 한 문자열로 만들면 그 자체가
  서버를 멈춥니다).
- 감사 로그에 대상·점검·열 수가 1행으로 기록됩니다.

## 9. API

| 메서드 | 경로 | 권한 |
|---|---|---|
| GET | `/api/svcmon/targets/export.csv?kind=&path=&tests=` | admin·operator |
| GET | `/api/svcmon/targets/sample.csv` | admin·operator |
| GET | `/api/svcmon/targets/csv-schema` | admin·operator |
| POST | `/api/svcmon/targets/import` (`{csv, mode:'preview'\|'add', expectedCount}`) | admin·operator |

`expectedCount` 를 함께 보내면 미리보기 이후 목록이 바뀐 경우 **409** 로 거부합니다(다른
사람이 그사이 등록했을 때 예상과 다른 수가 들어가는 것을 막습니다).

파일 다운로드는 브라우저 링크(`<a href>`)로 받을 수 없습니다 — 인증이 `Authorization: Bearer`
헤더만 인정하므로 `fetch` 로 받아야 합니다(화면은 `api.js downloadFile()` 을 씁니다).

## 10. 알려진 한계 (정직한 기록)

- **`replace`(기존 목록 최신화) 모드가 없습니다.** 가져오기는 추가·건너뜀만 합니다. 이유는
  `svcmon.json` 이 백업 대상에서 조용히 제외되기 때문입니다(백업 서비스의 파일 크기 상한 8MB,
  실측 15,000 대상 규모에서 16.4MB) — 복구 경로가 없는 상태에서 최대 2만 대상 삭제 기능을
  주지 않았습니다. 백업 문제를 고친 뒤 별도로 제공할 예정입니다.
- **기존 항목 갱신이 없습니다.** 이름·경로가 같은 대상은 건너뛰므로, 값을 바꾸려면 화면에서
  수정하거나 지우고 다시 넣어야 합니다.
- **오류 행만 CSV 로 내보내기**는 아직 없습니다.
- 상한(2,000행)과 용량 상수(워커당 62/s·16/s)는 **로컬 macOS 실측값**입니다. 운영(RHEL9·8vCPU)
  에서는 재측정을 권장합니다 — 특히 무응답 비중이 높은 환경은 타임아웃이 처리량을 지배합니다.
