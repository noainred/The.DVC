## 동작 변화(운영자가 알아야 할 것)

- 데모 계정(mock)은 operator 와 같은 판본을 받는다 — 관리 IP·계정명·서버 경로가 보이지 않고 CSV 내보내기는 403. 조회 자체는 그대로다.
- 범위 관리자는 `/tools/vm-clone` 에서 NFS 서버 주소·export 경로를 보지 못한다(`mountsMasked`). hostAccess 변경은 전체 범위 전용.
- 엣지 `idrac.json` 손상 시 export 503 — 중앙은 직전 값을 유지하고 '엣지 iDRAC 등록부를 읽지 못함' 을 말한다.
- VM 수량 추이: 비활성·점검중 vCenter 의 빈 목록을 diff 하지 않고 '부분 합' 으로 밝힌다.
- 게스트 디스크: 삭제된 vCenter 의 행을 지우고, 오래된 행은 합계에 남기되 표시한다.
- Prometheus `/metrics` 는 끊긴 호스트의 CPU·메모리 사용률 줄을 내지 않는다 · Summary·공개 API `clusters` 는 standalone 을 세지 않는다.
- 알림은 채널별로 따로 줄을 선다 · 일일 보고 '지금 발송' 이 그날 정기 발송을 대신하지 않는다(정한 시각 전이면) · **메일만 쓰는 현장에서 정기 보고가
  하루 내내 다시 나가던 것을 고쳤다**(리드 — 성공 판정이 메일 결과 'email:ok' 를 몰랐다).
- VM 구성 점검 알림은 목업 vCenter 의 VM 을 보내지 않는다.
- 엣지 CVP·SAN 포트 사용량 push 는 중앙 503 을 호출 안에서 다시 보내지 않는다(다음 주기 — 혼잡 503 도 한 주기 늦어진다).
- SAN 월간 점검: sensorshow 의 Warning·Above·Below·High·Low·Over*·Under*·Alarm*·Exceed* 는 '이상'(v2.742 의 '주의' 를 되돌림).
- CVP 조회 중 예산이 떨어졌는데 인터페이스를 못 읽은 장비는 '확인 불가'.
- 베어메탈 FC HBA 사용률 분모가 FC 표준 데이터율이다(16GFC = 1,600MB/s) — 같은 부하에서 예전보다 25% 높다.
- `/overview/trend` 의 서버 전력은 `?include=power` 일 때만 계산한다(화면은 쓰지 않는다).
- VM 프로비저닝 배치 칸 조회도 비활성·점검중·엣지 위임 vCenter 에 로그인하지 않는다(생성과 같은 문 — 리드).
