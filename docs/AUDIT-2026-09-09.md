## 즉시 조치 권고 (상위 5)

1. **S2 `toolsDenied` 서버 미집행** — 관리자가 통제를 걸었다고 믿는 상태에서 실제로는 열려 있다. `requireTool(k)` 미들웨어 + 회귀 테스트.
2. **S1 `installerPath` 임의 파일 유출** — AUTH_SECRET 유출은 전체 인증 체계 붕괴로 직결. 파일명 정규식 + realpath 화이트리스트.
3. **B1 `split(':')` 8곳** — 저장소 자신이 3곳에 정답 패턴과 금지 주석을 남겨둔 항목. 공용 `morefOf(id, vcenterId)` 로 통일.
4. **S3 pyportal 역할 강등 미반영** — 권한 회수가 8시간 동안 무효.
5. **S4 RMA 이력 DB 0600 누락** — 원격 명령의 stdout/stderr 가 다른 로컬 사용자에게 노출.
