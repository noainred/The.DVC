## 주요 확정 항목

- **A-01(high)** 메뉴를 읽지 못한 상태에서 편집 창이 기본 메뉴로 열리고 그대로 저장되면 내 메뉴가 지워졌다 — 화면은 조회 상태(loading·ok·error) +
  백오프 재시도 + 편집 잠금, 서버는 저장 때 직전 메뉴를 한 단계 보관(`prev{mode:'save'}`). 'v2.618 WEB-2 조회 실패 → 저장' 의 재발이다.
- **A-02(medium)** 사이드바 CSS 의 바닥 선택자(`.sb-label`)가 하단 상태바의 같은 이름 클래스를 바꿨다 → 사이드바 규칙을 전부 `.sb` 자손으로.
- **A-03/B-03(medium)** AD 계정 이름에 역슬래시·공백이 있으면 메뉴 조회가 500, 대소문자만 다른 이름이 다른 메뉴 → `menuUserKey`(소문자 · 안전 문자 밖이면 해시).
- **B-01/F-02(medium)** 게시판 쓰기 한 번 = 파일 전체 동기 재기록 + 합계 상한 없음 → 300ms 묶음 비동기 쓰기(종료 flush 등록) + 합계 상한 409 `board-full`.
- **C-01(medium)** v2.719 가 VM 스토리지 결측을 null 로 바꾼 뒤 소비처 12곳이 그 null 을 0 으로 더했다(디스크 추이 시계열·인벤토리 합계·정지 VM 회수량·공개 API) →
  합계에서 빼고 `vmStorageUnknown` 으로 센다. **결측을 null 로 바꾸면 소비처를 전수로 따라갈 것**(v2.599 기록의 재발).
- **F-01(medium)** VM 이동·구성 변경 이력 조회가 기간 안 일치 행 전부를 한 문장으로 정렬해 이벤트 루프를 멈췄다 → `trackedEventsAsync`(1일 조각 + 양보,
  결과 동일성 대조 · 최장 동기 구간은 비율로 고정).
- **D-01(low)** iDRAC 스캔 배정·GPU 게스트 배포 파일이 손상되면 엣지에 '배정 없음' 을 내려보냈다 → 503 `settingsUnreadable`(v2.631 규약의 누락 2곳).
