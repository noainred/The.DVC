## 주요 확정 항목

- **A-01 (high)** 장비 계정 인증(`auth:'device'`) 대상의 연결 시험이 요청 본문의 host 로 저장된 아이실론 비밀번호를 보낼 수 있었다 — v2.480
  '저장 비밀을 쓰면 host 도 저장값으로' 규약의 누락. 이제 등록부 주소로 고정한다(엣지 `/isidu-test` 가 가짜 SSH 서버 host 를 받아도 비밀번호가
  그쪽으로 가지 않는 것을 실제 접속으로 확인). **C-01** 엣지 `cleanEdgeTarget` 도 메인과 같은 SSRF 판정.
- **A-02** 엣지 시계가 앞으로 튄 결과가 '지금 수집' 완료 기준선을 미래로 굳혀 다음 요청이 영원히 끝나지 않았다(실제 centralRouter 로 재현).
- **A-03** 분리 실행 상태 출력을 연속으로 못 읽으면 시한까지 폴링했다 — 끊고 장비 작업을 멈춘다.
- **B-01** 서비스태그 교정으로 키가 바뀐 파트 장애가 장애별 보기에서 2건이었다(같은 시각 묶음 안의 key-migrated 닫힘 순서).

## 동작 변화

- 전송 속도 설정 PUT 은 범위 밖 숫자를 잘라 저장하지 않고 400 `bad-range` 로 거절한다 · 설정 파일 일시 읽기 실패 중 저장은 503 · 최신 표 정리 기준은 일 요약 보존일 ·
  CSV 응답은 Content-Length 대신 chunked(바이트는 같다).
- 업그레이드 서명: 키 파일에 형식 오류만 있는 설치본은 이제 서명 필수다(예전엔 키 미설정과 같이 경고만).
- 전체 소비 전력 응답의 `network.noTime` 은 더 싣지 않는다(CVP 판정에서 `never` 로 센다).
- uagmon 로그인은 비동기다(스레드 풀 scrypt) — 시도는 대조 전에 실패로 센다(동시 요청이 잠금을 우회하지 못하게).
