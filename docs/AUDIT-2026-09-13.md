## critical — 즉시 조치

### C-1 · `server/src/routes/central.js` · 중앙 agent 바인딩의 경로 정규화 우회

`/register-collector` 의 저장 키는 `body.name` 이므로 v2.488(H-1)에서 **헤더·쿼리와 별도로** 대조하도록 고쳤다.
그런데 그 대조가 `req.path === '/register-collector'` **정확 일치**에 걸려 있었다. Express 기본값은
`strict routing=false`·`case sensitive routing=false` 라서 아래 변형은 **핸들러에는 도달**하지만 그 비교가
거짓이 되어 대조가 통째로 건너뛰어졌다. 헤더·쿼리 `agent` 를 생략하면 미들웨어 대조도 0건이 된다.

최소 재현(Express 라우터 직접 실행):

| 요청 경로 | 상태 | 대조된 claim | 저장 키 |
|---|---|---|---|
| `/register-collector` | 403 | `edgeB` | — |
| `/register-collector/` | **200** | `""` | `edgeB` |
| `/Register-Collector` | **200** | `""` | `edgeB` |
| `/register-collector/.` | **200** | `""` | `edgeB` |

**영향**: 법인 A 의 침해된 엣지(유효 개별 토큰)가 법인 B 의 수집 서버 URL·토큰을 덮어쓸 수 있다. 그 뒤
중앙이 그 주소로 보내는 것에는 베어메탈 SSH 계정, iDRAC 계정, 엣지 새 비밀번호, 업그레이드 번들이 포함된다.
`server/CLAUDE.md` 가 "자격증명을 실어 호출하게 되는 유출 피벗" 이라고 명시한 바로 그 경로다.

**조치**: 대조를 미들웨어의 경로 비교에 의존하지 않게 **핸들러 안에서** 수행한다
(`registerBindingDenied`). 미들웨어 쪽은 `normPath()` 로 후행 슬래시·`/.`·대소문자를 정규화해 심층 방어한다.
회귀 테스트는 3개 변형을 모두 검사한다(기존 테스트는 정확 경로만 봐서 이 결함을 통과시켰다).

   "기능 권한은 서버가 진실의 원천" 규칙과 어긋난다. 기본 매트릭스 영향 검토가 필요해 후속으로 둔다.
5. **`toolsDenied` 부분 집행** — UI 도구 키 78개 중 41개가 `TOOL_PATH_KEYS` 미매핑이어서 거부해도 API 가 열린다.
   관리자가 화면의 '차단됨' 을 통제로 오인할 수 있다.
6. **저장 경로 host 변경 시 비밀 승계 — 나머지 레지스트리**(`vcenter`·`nsx`·`idrac`·`horizon`·`gpu/physical`·
   `collector`) — H1/H2/H4 와 같은 형태이나 폴러의 로그인 코드까지 개별 추적하지 않아 **추정**으로 남긴다.
   `secretCarry.js` 가 준비됐으므로 적용은 기계적이다.
7. **CSP 기본 비활성**(`index.js` — 환경변수 opt-in), **서버측 로그아웃 부재**, **WS 게이트웨이 JWT 쿼리스트링**,
   **백업 아카이브 평문**(설정 소유자 게이트로만 보호) — 모두 기존 문서화 항목이며 이번에 변경하지 않았다.
8. **엣지 재검증 누락**(`sanswitch`/`storage` `applyPulledDevices`) — 중앙이 내려준 device 를 엣지가 다시
   검증하지 않는다. 현재 중앙 저장·테스트 경로가 전부 검증을 타므로 도달 경로는 확인하지 못했다(심층방어 결함).
9. **미인증 `/auth/config` 의 초기 비밀번호 파일 경로** — 코드에 "이미 문서에 공개된 고정 위치이고 값은 절대
   싣지 않는다" 는 근거가 적혀 있어 **의도적 설계로 판단해 변경하지 않았다**. 부트스트랩이 끝나면 노출이 멈춘다.
