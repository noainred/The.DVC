## 주요 확정 결함

- **CEN2600-01 (high)** 엣지 `gpu-guest-data` 의 `utilPct` 객체 하나가 **함대 전 지표 적재를 매 분 롤백**했다 → `narrowGpuRow` + `gpu/store.js` 2차 방어(`pctOrNull`).
- **T2600-01·02** 로그인 잠금 Map 키에 길이 상한이 없어 무인증 OOM · 하한캡 퇴출이 **활성 잠금부터** 지워 분산 실패로 잠금 해제 → 키 128자 초과는 sha256 · 퇴출은 잠금 없는 카운터부터 · `routes/auth.js` 는 256자 초과 사용자명을 인증 전에 400.

## 정직 기록 — 확인하지 못한 것

- 비-admin 가림 안내·NSX 목록 실패 표시·스토리지 carry-forward 경고는 목 데이터로 만들 수 없어 **브라우저로 보지 못했다**(순수 함수·실제 라우터 테스트로 확인).
- 실장비: xmcli 빈 칸 형식(COL-04)·Isilon v1 경보 폴백·nvidia-smi 오류 줄·porterrshow 머리글 변형은 합성 입력 재현이다.
- 원격 `/tmp` 선점 공격 체인은 원격 sshd 가 없어 전체를 재현하지 못했다.
- vmseries `cover_batch` 는 엣지가 generatedAt 을 안 보내면 cover 내용으로 판정한다 — 서로 다른 주기의 cover 가 우연히 같을 가능성은 실측하지 않았다.
