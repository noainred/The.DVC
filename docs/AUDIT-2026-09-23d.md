# v2.582 — 아키텍처 점검·버그 수정·튜닝 4차 (2026-09-23)

사용자 요청: "아키텍처 점검, 버그 수정, 튜닝 진행해서 **각각 5개씩** 찾아줘". v2.579(의존 그래프·풀 사본) ·
v2.580(웹 그래프·SQLite open·세대 캐시) · v2.581(SQL 실행계획·동기 fs)이 보지 않은 축을 골랐다.

## E. 정직 기록

- 타이머 인벤토리·메모리 시계열은 목 서버 3분 관측이다. 운영 폴러 구성이 다르면 순위가 다를 수 있다.
- ARCH-4 의 `exit` 훅은 SIGKILL·정전에서는 동작하지 않는다 — 그 경우는 ARCH-3 원자 쓰기가 절단본만 막는다.
- BUG-5 는 실제 운영 호스트의 TZ 를 확인하지 못했다. 패키지 unit 에 TZ 가 없다는 사실과 코드가 `getHours()` 를 쓴다는 사실만으로 판정했다 — 호스트가 KST 라면 증상은 없었을 것이고, 수정 후에는 호스트 TZ 와 무관해진다.
- 이 회차의 작업 현황 표에 한 번 **시계를 읽지 않은 추정 시각(09:38)** 을 적었다. 사용자가 지적해 09:04(`date`) 로 정정했다 — 표의 시각은 `date` 출력만 쓴다.
