## 성능

측정(MOCK_SCALE=3, 4.5분 + CPU 프로파일): 정상 상태 루프 지연 p99 10.7~13.5ms · 30초마다 45~65ms 스톨 1회(`store.refresh`) · 힙 평탄(누수 징후 없음).
PERF2620-01 백업 동기 gzip 은 비동기로 바꿨다(정지의 약 1/3 — `JSON.stringify` 몫은 남음). PERF2620-02(LRU 가 prune 핸들 닫음)는 현재 도달 불가라 보류.

## 정직 기록

- 실장비(vCenter·Horizon·NSX·스토리지의 실제 리다이렉트 동작, 공유 토큰 엣지가 NAT 뒤에 있는 현장)로는 확인하지 못했다 — 전부 가짜 서버·합성 입력 재현이다.
- 리다이렉트 거부는 **동작 변경**이다: 등록 주소를 http 로 적어 두고 장비의 https 리다이렉트에 기대던 현장은 이제 '리다이렉트로 응답했습니다(HTTP 30x)' 오류를 받는다. 조치는 등록 주소를 https 로 고치는 것이다(Basic 인증 경로는 교차 출처 리다이렉트에서 이미 인증 헤더가 떨어져 실패했을 것이다).
- 스캔 대역 조회를 fleetOnly 로 바꿔 범위 관리자는 iDRAC 스캔 화면에서 권한 안내를 본다(의도된 변경 — `audit2611b` 기대값 정정).
