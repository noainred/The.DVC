### F1 — OFL 3조(예약 폰트 이름) 위반 **확정** → 폰트 이름 변경

`fontTools` 로 두 파일을 직접 디코드해 확정했다:

`Pretendard-OFL.txt:2` 가 **"with Reserved Font Name Pretendard"** 를 선언하고, OFL 의
"Modified Version" 정의는 *"adding to, **deleting**, or substituting … **by changing formats**"*

금지한다.
→ `name` 테이블을 **`DVC Sans KSX`**(nameID 1/4/6/3)로 바꿨다. **nameID 0(원저작자 저작권)은
OFL 1조가 보존을 요구하므로 그대로 둔다.** jsPDF 별칭도 `DVCSansKSX` 로 바꿨다(그 값이 PDF 의
폰트 리소스 이름이 된다).
