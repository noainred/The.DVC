## 문서화·수용된 잔여 리스크 (신규 아님 — 재확인)

- **공유 CENTRAL_TOKEN = 전체 신뢰**: 공유 토큰 모드(`mode:'shared'`)에선 agent 바인딩 검사가 단락되어 토큰 하나로
  `?agent=`만 바꿔 임의 엣지의 자격증명(SSH 비번·passwordHash·iDRAC 평문 비번) 인출 가능. per-agent 토큰이 완화하려는
  바로 그 리스크이며 완전 봉인은 `CENTRAL_REQUIRE_AGENT_TOKEN=true`. 코드 주석에 명시된 의도된 하위호환.
- **relayProbe DNS 리바인딩 TOCTOU**(`vcenter/relayProbe.js`): `ssrfBlockReasonResolved` 통과 후 재해석 연결. admin 게이트 +
  단계 성공/실패 오라클만 반환. 주석이 best-effort로 명시한 기존 한계.
- **`fetchRemoteVersions(baseUrl)`**(`upgrade/deployLlm.js:39`의 `req.query.baseUrl`): SSRF 미검증이나 admin 게이트 +
  JSON 파싱만 + 다운로드는 sha256 강제. 경미.
- **`security-session.json` 손상 시 `preserveCorrupt` 미적용**(`security/securitySettings.js:37-39`): 파싱 실패를 조용히
  DEFAULTS로 리셋. 단 fail-safe 방향(소유자는 `noainred`+파일/env로 병합돼 아무도 안 잠김, 로그인정책은 엄격 복귀).
  유일한 실질 결과는 UI 저장 소유자·완화 정책의 조용한 소실.

## 유지 확인된 불변조건 (회귀 없음)

- **인증/인가**: `verifyToken`은 `resolveTokenUser` 내부에서만 호출(직접 신뢰 경로 없음). WS SSH/RDP 게이트웨이가
  핸들러 내에서 `resolveTokenUser`+`mustEnrollOtp`+`userHasPermission('remote.access')` 직접 검사. 단건 `:id` 라우트
  `inUserScope` 404 은닉. memoJson scopeKey 일치. 검색/도구/IPAM scope 전면 적용. OTP/로그인 정책(`isOtpOnlyUser` 재정의·
  enroll 시 조건부 passwordHash 삭제·`requireEnrolled`) 유지. 미인증 `/auth/config` 계정명 미포함.
- **central/SSRF/업그레이드/TLS**: `setGlobalDispatcher` 전역 무검증 없음. `WAN_TLS_INSECURE`는 `=== 'true'`만 해제(반전 없음).
  central agent 바인딩 미들웨어 + 소유권 검사. GPU 오버레이 direct-mode 봉인(최장 프리픽스 매칭). SSRF 가드(8/10/16진수·
  IPv4-mapped·링크로컬/루프백/ULA 정규화). uagmon 리바인딩 방어(연결 직전 재해석+IP 핀+비번 미이월). 업그레이드 sha256
  3경로 검증(부재도 거부) + 경로 탈출 이중 방어 + tar 정규 파일만 추출.
- **주입/명령/WS**: SQL 전 쿼리 파라미터 바인딩. 경로 탈출 이중 방어(업그레이드·로그 다운로드). 원격 명령 출력(유닛명·경로)
  재검증. RDP 티켓 fail-closed(1회용·60s·인메모리). guacd 길이접두 인코딩. 프로토타입 오염 방어(`Object.create(null)`·`__proto__` 차단).
- **자격증명/파일**: 4종 자격증명 스토어 `atomicWriteFileSync`+`preserveCorrupt` 대칭. 백업 라우트 7종 `adminOnly`+
  `requireSettingsOwner`, 확장자 화이트리스트 `.json`/`.env`(.txt 소유자 파일 제외). 비밀값 로그/응답 미노출. 특수 계정
  (`noainred`·`thedvcdemp`) 보호. `parseUploadedArchive`는 미연결 죽은 코드(업로드-복원 우회 없음).
- **pyportal**: CSRF(상태변경 커스텀 헤더 필수+Origin/Sec-Fetch-Site 403). 미인증 포트 스캐너 차단(커스텀 urls 세션 필수+
  30s 쿨다운). SSRF 해석 주소 전수 검사+스킴 화이트리스트+리다이렉트 미추적. 웹훅 저장·전송 이중 검증. XSS(innerHTML/eval
  없음, `textContent`만, CSP `default-src 'self'`). CSV 인젝션 방어(`= + - @` 선두 셀). 세션 HMAC 서명+`compare_digest`+
  tokenVersion+발급시각 컷오프. 미인증 응답 경로/설치상태 은닉. 본문 drain·소켓 타임아웃 20·연결 세마포어 64.
- **프론트/버그**: `dangerouslySetInnerHTML` 0건(유일 HTML sink Topology3D `nodeLabel`은 `escHtml`+`Number()`). React #310
  위반 없음(조기 return은 전부 헬퍼 컴포넌트 내부, 메인 훅은 return 위). 폴러 재진입 가드 전수 존재. 대량 write 트랜잭션.
  ipam 이중 연결 상호배타(SQLITE_BUSY 불가). 자원 누수 없음(C 라이브러리 한계 1건 제외).

## 권고 우선순위

1. **발견 1(Medium)** — `listSources`/`getPlacement`/`listSaved`에 `scopedVcenterIds(req.user)` 교집합 + 조회 라우트에
   `requirePerm('vm.provision')`(또는 `tools`) 게이트. 유일한 Medium.
2. **발견 4·5·2** — 한 줄 게이트(`requirePerm('remote.access')`/`inUserScope`/scope 교집합) 부착으로 즉시 해소.

5. 성능 잔여 A — `historyAll`에 SQL LIMIT 도입 또는 시간당 롤업 경로로 상한.
