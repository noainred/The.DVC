# 글로벌 데이터센터 서비스 허브 (pyportal) — 운영 가이드

운영에 쓰는 **여러 서비스 포탈(Grafana·NetBox·ServiceNow·Vault·백업 콘솔 …)을 한 화면에 모아 두는
바로가기 허브**입니다. 설정에서 **이름과 URL**만 입력하면 대시보드에 바로가기 카드가 즉시 생성되고,
링크 상태 점검·데이터센터 현황 지도·점검 이력 차트까지 제공합니다.

> **모니터링 포탈(Node/React)과 완전히 분리된 별도 페이지·별도 프로세스**입니다. 포트만 다르게 띄우면
> 되고 인증·데이터가 서로 얽히지 않습니다. 소스·기술 문서(환경변수·REST API·테스트)는
> [`pyportal/README.md`](../pyportal/README.md), 설치 절차는 [INSTALL.md §10.1](INSTALL.md) 참고.

- **언어/의존성** — Python 3.9+ **표준 라이브러리만**(pip 설치 불필요). 프런트엔드도 빌드 도구·CDN·차트
  라이브러리 없이 순수 HTML/CSS/JS라 인터넷이 막힌 Rocky 9 서버에 복사만으로 올라갑니다.
- **빠른 실행** — `cd pyportal && python3 app.py` → `http://<서버>:8095`

## 화면 구성

| 화면 | 내용 |
|---|---|
| 서비스 바로가기 | 즐겨찾기 · 카테고리 필터 칩 · **다중 키워드 검색**(v2.218, 아래) · 최근 점검 배지 |
| 센터 현황 | 좌표 지도 · 센터별 전용 링크 · **표시 개수는 설정에서 지정**(0=전체) |
| 링크 상태 점검 추이 | 점검 이력 SQLite 기반 가용률·평균 지연 차트(아래) |
| ⚙ 설정 | 로그인 보호(아래) — 바로가기/데이터센터/카테고리/사용자/백업/알림·감사 관리 |

### 디자인 — 클로드×블루 (v2.228) + Pretendard 번들 (v2.224)

**클로드 디자인 언어 × 블루 팔레트**입니다: 세리프 대제목·큰 모서리(18~22px)·부드러운 보더·넉넉한
여백에 네이비 배경(`#0C1322`) + 밝은 블루 액센트(`#4C8DFF`) — 실제 화면 컴포넌트로 만든 A/B 시안
비교 후 선택된 디자인입니다(v2.228). 스타일은 `pyportal/static/styles.css` 단일 파일입니다
(CSP 정책상 인라인 style 금지 — 색은 CSS 클래스로).
글자체는 **Pretendard Variable**(OFL)을 `static/fonts/`에 번들해 접속 PC의 설치 폰트와 무관하게
전부 동일·선명하게 표시됩니다(오프라인 동작, 외부 CDN 없음, 폰트는 1년 장기 캐시).

### 검색 — 다중 키워드 AND (v2.218)

상단 검색에 **두 단어 이상**을 입력하면 모든 단어가 포함된 항목만 나옵니다(예: `grafana 서울`).
바로가기와 데이터센터 검색에 동일하게 적용됩니다. 검색 대상: 이름·URL·설명·태그·카테고리 라벨.

## ⚙ 설정 (로그인 보호)

상단 우측 **[🔒 설정]** 버튼은 잠겨 있고, 첫 기동 때 임의 생성되어
`$HUB_DATA_DIR/initial-settings-password.txt`(0600)에 저장된 **초기 비밀번호**로 들어갑니다
(비밀번호 변경 시 파일 자동 삭제). 로그인은 **사용자명 + 비밀번호**입니다(v2.216).
역할은 `admin`(전체) / `viewer`(바로가기까지). **조회는 공개, 상태 변경은 전부 로그인 필요.**
세션은 서명 토큰이라 **서비스를 재시작해도 로그인이 유지**됩니다(v2.215).

하위 메뉴 6개:

| 메뉴 | 내용 |
|---|---|
| 🔗 바로가기 관리 | 등록/수정/삭제 · ↑↓ 표시 순서 · **CSV 가져오기/내보내기**(v2.216) |
| 🏢 데이터센터 구성 | 사이트 편집 + **화면 표시 개수 지정**(0=전체) · ↑↓ 순서 |
| 🏷️ 카테고리 구성 | 분류를 직접 생성 — 이름·색상(8종 팔레트)·순서. 삭제 시 그 바로가기는 기본 카테고리로 이동(v2.216) |
| 👤 사용자 구성 및 설정 | 계정 추가/중지/삭제 · 비밀번호 변경(초기 비밀번호 파일 자동 삭제) |
| 💾 현재 설정 백업 | 즉시/주기(30분~1주) 백업 · 보관 수량 · 받기/복원(복원 직전 상태 자동 백업) · **가동 판정 기준**(포트/HTTP) |
| 🔔 알림 & 감사 로그 | 상태 전환 웹훅 알림 · `audit.log` 조회(admin 전용, v2.215) |

### 즉석 카테고리 생성 (v2.218)

바로가기를 **등록/수정하는 중에** 카테고리 선택 목록 맨 아래 **"＋ 새 카테고리 만들기…"** 를 고르면
이름을 물어 즉시 생성하고 자동 선택합니다 — '카테고리 구성' 화면까지 갔다 오는 왕복이 없습니다.
취소하거나 실패하면 직전 선택으로 되돌리며, 생성 권한(admin)은 서버가 검사합니다.

### 바로가기 CSV/JSON 가져오기·내보내기 (v2.216, JSON 선택 v2.219)

엑셀에서 정리한 표를 그대로 올리고(같은 URL은 건너뜀), 내보낸 CSV는 백업으로도 씁니다.
RFC 4180 파서 + CSV 인젝션 방어(`= + - @` 셀 무력화) + UTF-8 BOM(엑셀 한글).
열: `name,url,category,icon,description,tags,datacenterId,isFavorite`.
**CSV·JSON 모두 가져올 때 방식을 선택**합니다(v2.219): 기존 목록 뒤에 **추가**(같은 URL 건너뜀,
기본) 또는 파일 내용으로 **통째 교체**(덮어쓰기 — 되돌릴 수 없어 한 번 더 확인).
가져올 때 **일괄 카테고리**도 지정할 수 있습니다(v2.220) — 이름/ID로 입력하며 없는 분류는
admin에 한해 즉석 생성됩니다(슬러그 충돌 시 자동 고유화, v2.223). 또한 **바로가기 관리 표의
카테고리 열이 드롭다운**이라 수정 화면 없이 표에서 바로 분류를 바꿀 수 있습니다(v2.220).

**서버 파일 직접 가져오기(v2.223)** — 데이터 폴더의 `import/` 디렉터리(운영:
`/etc/dc-service-hub/import/`)에 `.json`/`.csv`를 올려 두면 [🗂 서버 파일 가져오기]로 업로드
없이 반영합니다(admin 전용). scp로 올린 파일·자동화 산출물을 폐쇄망에서 등록할 때 씁니다.
파일명 화이트리스트 + 경로 탈출 차단 + 2MB 상한이 걸려 있고 감사 로그에 원본 파일명이 남습니다.

### 버전 표시 (v2.219)

헤더 제목 옆과 푸터에 허브 버전이 표시됩니다. 저장소째 배포에서는 `package.json`의 포탈 버전을
자동으로 읽어 동기화되고, 단독 복사 배포에서는 내장 폴백(또는 env `HUB_VERSION`)을 씁니다.

## 링크 상태 점검 · 알림

- **가동 판정 기본은 포트 응답**(v2.216) — 사내 서비스는 로그인 리다이렉트·401/403을 정상적으로
  돌려주므로 HTTP 코드 판정이면 멀쩡한 서비스가 계속 '확인 필요'로 뜹니다. 설정 › 현재 설정 백업의
  '가동 판정 기준'에서 HTTP 코드 기준으로 바꿀 수 있습니다.
- **점검 이력 DB + 기간별 차트** — 결과를 SQLite(WAL)에 적재하고 **5분~한달** 구간의 가용률·평균 지연
  추이를 SVG 차트로 보여줍니다(개별 링크 필터). 보관 기간 `HUB_HISTORY_RETENTION_DAYS`(기본 40일).
- **상태 전환 알림(v2.215)** — 링크가 **정상↔장애로 바뀌는 순간에만** 웹훅으로 알립니다(연속 실패
  임계·최소 간격으로 플래핑 억제, 기동 직후 첫 관측은 알리지 않음). [테스트 전송] 지원.
- **감사 로그(v2.215)** — 로그인·설정 변경·사용자 추가/삭제·백업 인출을 `audit.log`(JSON Lines,
  0600, 회전)에 기록. 비밀값(password/token/secret)은 기록하지 않습니다.

## 보안 (6차 감사 v2.214 + 후속)

- 스킴 화이트리스트(`javascript:` 저장 차단), **SSRF 가드**(루프백·169.254.169.254 등 차단,
  RFC1918은 사내 대상이라 허용), 리다이렉트 미추적, `default-src 'self'` CSP, 정적/백업 경로 탈출 차단.
- **CSRF 차단** — 쿠키 자격증명은 조회(GET/HEAD) 전용, 상태 변경은 커스텀 헤더 필수 + 교차출처 403.
- **임의 URL 점검은 로그인 필수**(사내망 포트 스캐너 악용 차단), 미인증 재점검은 30초 쿨다운.
- **IP별 로그인 잠금**(전역 잠금으로 정상 관리자가 밀려나지 않게), 소켓 타임아웃·동시 연결 상한.
- 비밀번호 pbkdf2(21만 회), 웹훅 URL은 저장·전송 시점 모두 SSRF 검증, 백업 파일 0600(admin 전용).
- 포탈 전체를 비공개로 하려면 `HUB_TOKEN`을 설정합니다. 허브는 기본 **평문 HTTP** — 사내망 밖에
  노출한다면 리버스 프록시로 TLS를 씌우세요.

## 로그인이 안 될 때 (복구 절차, v2.225)

증상별 복구 경로 — 위에서부터 순서대로 확인하세요.

1. **초기 비밀번호를 모른다(설치 직후)** — 계정은 `admin`, 비밀번호는
   `sudo cat /etc/dc-service-hub/initial-settings-password.txt` (비밀번호 변경 전까지만 존재).
2. **로그인 실패 잠금에 걸렸다** — 같은 IP에서 8회 실패 시 5분 잠금(기본). 5분 기다리거나
   `sudo systemctl restart dc-service-hub`(잠금 카운터는 메모리라 재시작으로 초기화).
3. **비밀번호를 잊었다 / 관리자 전원이 잠겼다** — 서버 콘솔에서 비밀번호 초기화:
   ```bash
   sudo -u dchub python3 /opt/dc-service-hub/app.py --data-dir /etc/dc-service-hub --reset-password admin
   # → 새 임의 비밀번호가 출력됩니다. 기존 세션은 전부 무효화되고, 서비스 재시작은 필요 없습니다.
   sudo -u dchub python3 /opt/dc-service-hub/app.py --data-dir /etc/dc-service-hub --list-users   # 계정 확인
   ```
   계정이 아예 없거나 전부 삭제된 경우에도 같은 명령이 그 이름의 **admin 계정을 새로 만들어** 줍니다.
   파일시스템 접근 권한(=서버 운영자)이 곧 인증이며, 실행 내역은 감사 로그에 `console` 주체로 남습니다.
   ⚠️ root 로 실행하면 users.json 소유권이 root 가 되어 허브가 쓰지 못할 수 있으니 `sudo -u dchub` 를 유지하세요.
4. **`HUB_TOKEN`을 잊었다(포탈 전체 비공개 모드)** — systemd 유닛의 `Environment=HUB_TOKEN=` 값을
   확인/교체 후 재시작: `sudo systemctl cat dc-service-hub | grep HUB_TOKEN`.

## 운영

- **상시 구동** — `pyportal/systemd/dc-service-hub.service`(전용 계정 `dchub`,
  `ProtectSystem=strict`). 설치 절차는 [INSTALL.md §10.1](INSTALL.md) 참고.
- **모니터링 포탈과 상호 링크(v2.215)** — 포탈에 `SERVICE_HUB_URL`을 주면 특수 기능에 '서비스 허브'
  카드가, 허브에 `HUB_PORTAL_URL`을 주면 헤더에 [모니터링 포탈 ↗]이 나타납니다. 인증은 각자
  유지합니다(연동하지 않는 편이 안전).
- **저장** — 설정 JSON(0600, 원자적 쓰기, 손상 시 `.corrupt.<ts>` 보존) + 이력 SQLite(WAL, `ts` 인덱스).
- 오프라인 설치 패키지/업그레이드 번들에 `pyportal/`이 함께 포함됩니다(기동은 운영자가 선택).
