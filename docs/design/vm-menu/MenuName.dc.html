  • 화면 제목(상단의 큰 글자)

  • 메뉴 편집 화면의 항목 이름
  • 기능 사용 현황의 항목 이름
  • Physical Server(‘· Baremetal’ 을 뗌) — 그 화면 안의 안내 글 두 줄도 같은 이름으로

  • 위 숫자 3장의 ‘Virtual Machine · VM’ 이름
  • Physical Server 가 여는 화면(구분 Baremetal 고정)
