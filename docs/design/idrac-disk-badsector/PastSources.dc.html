순서 (제안)
1단계디스크 값 · 시스템 이벤트 로그 읽기만 합니다. 6시간 점검에 함께 넣습니다. 판정에 ‘흔적 있음 · 날짜 모름’ 과 ‘디스크 값 모름’ 이 생깁니다. 위험: 낮음. 값을 주지 않는 서버가 많으면 얻는 것이 적습니다.
2단계보관 로그 내보내기 관리자가 누를 때만, 법인 노드에서 한 번에 한 대. 과거의 날짜 있는 기록을 읽는 유일한 길입니다. 위험: 보통. 이 기능이 장비에 보내는 첫 요청형 동작입니다. 파일 크기 · 시한 · 압축 해제 상한을 둡니다.
3단계세션 재사용 iDRAC 를 읽는 모든 기능이 쓰는 접속 코드를 바꿉니다. 장비마다 세션 하나, 못 받으면 기존 방식으로 둡니다. 위험: 높음. 세션이 새면 장비의 세션 한도를 채워 다른 사람이 접속하지 못할 수 있습니다. 따로 검증합니다.

장비 설정을 포탈이 바꾸는 것 — 텔레메트리 보고서 켜기 · 로그인 묶기 켜기. 상태만 보여 주고 방법을 안내합니다.
걸러 읽기 — 활성 로그 안에서만 걸러지므로 과거를 읽지 못합니다. 지금 전체 읽기가 9초라 급하지 않습니다.
공유 폴더로 내보내기 — 장비가 포탈 쪽 공유에 쓰게 하려면 자격증명과 방화벽 설정이 필요합니다.
