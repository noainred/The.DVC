3근거와 한계

  • 근거 외부 문서를 검색 요약으로 확인했고 원문은 열지 못함. 실장비 대조 0건.
  • 로그가 남은 구간만 봅니다. ‘기록 없음’ 은 ‘발생한 적 없음’ 이 아닙니다.
  • RAID 로 묶이지 않은 디스크(HBA · vSAN)는 로그로 볼 수 없습니다.
  • 교체된 디스크의 모델은 로그에 없어 모델별 비율이 낮게 나옵니다.
  • 가상 디스크와 OS 장치를 못 맞추면 ‘확정하지 못함’ 으로 둡니다.
  • 추가 기능의 디스크 값 · vSAN 상태 · 컨트롤러 설정은 읽는 방법이 미확인입니다.
