디스크 배드 섹터 이력 점검 기능 — 설계 요약

보고일 2026-11-14 · 기준 버전 v2.914.0
단계 화면 시안 완료 · 구현 전
요약 — 서버 디스크에 과거 배드 섹터가 났는지, 그 디스크를 아직 쓰고 있는지, 지금 어디에 쓰이는지를 포탈에서 찾는 기능입니다. iDRAC Lifecycle 로그를 법인 엣지가 6시간마다 읽어 중앙에 쌓습니다. 화면 시안 7장과 근거 문서 정리를 마쳤고, 실장비 확인 뒤 구현합니다.

1배경 — 지금은 답할 수 없습니다

  • 포탈은 iDRAC 로그의 끝 40건 가운데 경고 · 위험 15건만 보고, 기록 ID 는 버립니다.
  • 지난 기록을 쌓아 두는 곳이 없어 로그가 넘어가면 사라집니다.
  • 법인 엣지를 거치는 서버는 중앙에서 바로 조회할 수 없습니다.

4근거와 한계

  • 근거 외부 문서 32건 정리. 웹 검색 요약으로 확인했고 원문은 열지 못함. 실장비 대조 0건.
  • 로그가 남아 있는 구간만 봅니다. ‘기록 없음’ 은 ‘발생한 적 없음’ 이 아닙니다.
  • RAID 로 묶이지 않은 디스크(HBA · vSAN)는 이 방법으로 볼 수 없어 따로 셉니다.
  • 교체된 디스크의 모델은 로그에 없어 모델별 비율이 실제보다 낮게 나옵니다.
  • 가상 디스크와 OS 장치를 맞추지 못하면 ‘확정하지 못함’ 으로 둡니다.
  • 고장 예측(PDR16)은 배드 섹터와 다른 뜻이라 따로 셉니다.
