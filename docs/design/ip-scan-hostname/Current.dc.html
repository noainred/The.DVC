지금 — IP 관리 › 대장 목록 · 스캔 설정 v2.914.0 목 서버 캡처 · 스캔 결과 12건은 이 시안을 위해 심은 가상 데이터(이름 있는 것 3건)
1‘호스트명’ 열이 없습니다. 스캔 IP 의 이름은 ‘소유 자원’ 칸에, 그리고 표 오른쪽 끝 ‘ESXi 호스트’ 칸에 한 번 더 들어갑니다(잘려 보이는 gw… · lnx… · esx…).
2이름을 찾는 방법은 역DNS 하나입니다. PTR 레코드가 없는 IP 는 ‘소유 자원’ 칸에 IP 가 그대로 다시 적힙니다(10.210.5.11 · SMB,RDP,WinRM).
3이름을 어디서 알았는지 표시가 없습니다. 직접 넣은 이름(관리상태 편집 › 호스트명)과 스캔이 찾은 이름이 같은 모양입니다.
4이름이 없는 IP 만 모아 볼 방법이 없습니다. 출처 대조 칩에 ‘스캔만’ 은 있지만 ‘호스트명 없음’ 은 없습니다.
5스캔 IP 를 누르면 안내 창뿐입니다. 열린 포트 · 이름 · 최초/마지막 확인 · 사용 이력이 나오지 않습니다(‘IP 사용 이력’ 창은 서브넷 대장에서만 열립니다).
6스캔 설정에서 이름과 관련된 칸은 ‘역DNS 호스트명’ 하나이고, 스캔이 이름을 몇 개 찾았는지는 어디에도 나오지 않습니다.
코드에서 확인한 것 스캔은 응답한 IP 에 대해 dns.reverse() 만 부릅니다 — server/src/ipam/scan.js ‘reverseMany’. mDNS · NetBIOS 같은 다른 방법은 없습니다. 엣지가 보낸 결과에서 중앙이 받는 칸은 IP · 열린 포트 · 서비스 · 호스트명 넷뿐입니다 — server/src/ipam/scanStore.js ‘cleanAliveHost’. 출처를 실으려면 이 목록도 함께 넓혀야 합니다. 대장의 스캔 행은 ownerName = 호스트명 또는 IP · hostName = 호스트명 으로 만들어지고, 목록은 hostName 을 ‘ESXi 호스트’ 라는 제목의 열에 그립니다 — ledger.js · IpamCore.jsx. 직접 넣는 이름은 이미 있습니다 — ‘IP 관리상태 편집 › 호스트명(자동 수집 호스트명을 덮어쓸 이름)’, IpamEditors.jsx. Angry IP Scanner 의 Hostname 칸은 공개 소스 기준으로 역DNS → mDNS(UDP 5353 멀티캐스트) → NetBIOS(UDP 137) 순서입니다. mDNS · NetBIOS 는 그 프로그램이 ‘로컬(LAN)’ 로 판정한 대상에만 시도합니다.
