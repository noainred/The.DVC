호스트명 열 — IP 바로 옆에 둡니다(표가 가로로 넘겨도 IP 와 함께 보입니다). 배지는 그 이름을 어디서 알았는지입니다: 역DNS · mDNS · NetBIOS · 수동.
표시 순서 — 직접 넣은 이름 > 역DNS > mDNS > NetBIOS. 방식마다 이름이 다르면 ‘이름 다름’ 을 붙이고, IP 를 누르면 방식별 결과를 보여 줍니다.
못 찾은 IP — ‘—’ 로 두고 지어내지 않습니다. ‘+ 이름’ 은 지금 있는 ‘IP 관리상태 편집 › 호스트명’ 칸을 바로 엽니다(운영자 · 관리자).
소유 자원 · ESXi 호스트 칸 — 스캔 행은 소유 자원 칸에 열린 서비스만, ESXi 호스트 칸은 ‘—’(지금은 두 칸에 이름이 중복으로 들어갑니다).
