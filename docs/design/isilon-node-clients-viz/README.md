## 1. 요구

사용자 원문(2026-11-10 08:30 KST): "노드별 어떤 클라이언트와 통신한는게 한눈에 잘 안보이는데, 클로드 디자인 사용해서 시각적으로 잘 보이게
개선해줘, 시안을 5개정도 보여주고, 1개는 3D 로 만들어줘".

지금 화면(v2.950.0 노드 부하 구역)의 한계 — 히트맵·소형 다중·겹쳐 보기는 **노드별 부하 값**만 보여 주고, '누가 붙었나' 는 노드를 하나씩 눌러
드로어(`NodeClientsDrawer.jsx`)를 열어야 보인다. 클라이언트 분포 보기(`ClientDistView.jsx`)는 **클라이언트 → 노드** 방향의 표라 노드 축에서
한눈에 들어오지 않는다. 그래서 '노드 ↔ 클라이언트' 를 **한 장**에 올리는 보기를 추가하는 것이 이번 설계의 범위다.

## 2. 공통 전제 (시안 5개 전부 같다)

- **데이터는 지금 있는 응답 그대로** — `GET /tools/storage/devices/:id/client-dist`(창·클라이언트 × 노드 ops · 노드 합 · 쏠림 · 고정 판정)와
  `node-clients`(드로어). 새 서버 작업 없음, 장비 호출 0. 값은 **창 평균 ops/s** = 합 ÷ `nodeLoadSampleCount`(클라이언트 분포 보기와 같은 숫자).
- 모든 시안은 노드 부하 구역의 **'보기' 세그먼트 한 칸**(클라이언트 분포 옆)으로 들어가고, 노드를 누르면 **기존 드로어**가 열리고,
  클라이언트를 누르면 드로어의 그 줄로 스크롤한다(`scrollKey`). 새 셸·새 화면을 만들지 않는다.
- 프로토콜 색: nfs `#3987e5` · smb `#d95926` · http `#199e70`(겹쳐 보기 4색과 같은 검증기 통과 색). 쏠린 노드 `#c98500`/`#fcd34d` · 빈 노드 점선.
- **'최근 작업 없음'(노드 3) 은 '연결 없음' 이 아니다** — 창 표본에 그 노드로 온 클라이언트가 없다는 뜻. 모든 시안이 이 문구를 그대로 쓴다.
- 이름은 포탈 인벤토리에서만 붙인다(역방향 DNS 없음 — `storage/clientNames.js`).

three.js 시안은 만들지 못했고, 구현 B 는 **미검증 대안**으로만 적는다(번들 크기 '약 600KB' 는 기억 기반 추정이라 구현 전에 실측할 것).

## 4. 추천

1. **① 현 다이어그램을 기본 보기**로 — 질문("노드별 어떤 클라이언트와 통신하나") 에 가장 직접 답한다.
2. **③ 노드 카드**를 노드 수가 많을 때(또는 400px) 전환용으로 — 구현이 가장 싸고 드로어와 바로 이어진다.
3. ④ 매트릭스는 분석·내보내기용 보조, ② 생키는 프로토콜 질문이 잦을 때만.
4. 3D 를 원하면 ⑤ 를 '보기' 옵션으로 두되 400px 평면 폴백(③)을 같이 만든다.

## 5. 정직 표기 · 확인한 것과 못 한 것

- 수치·IP·이름은 **가상**이다. 실장비 표본 모양(REST summary · `isi statistics` JSON)은 **아직 미확인**(v2.937 설계 §8 과 같은 상태).
- 다섯 장 전부 **로컬 Chromium 1440×900 렌더로 직접 봤다**(③④⑤ 는 Playwright 스크린샷 판독 — ④ 는 첫 렌더에서 열 수가 14 로 잘못 선언돼
  격자가 어긋났고, ⑤ 는 뒷줄 노드 명판이 앞줄 기둥에 가려 기둥 위로 옮겼다 → 둘 다 고친 뒤 올림). 캔버스 자체(디자인 도구 안 표시)는 도구 규칙대로
  따로 검증하지 않았다.
- ⑤ 의 라벨 15개는 **손으로(스크립트의 겹침 검사로) 배치**했다. 실데이터에서는 자동 배치(겹침 회피)가 필요하다.
- 구현 규모(줄 수)는 **추정**이다. 캔버스 메모의 '클라이언트 14' 는 실제 15 라 정정했다(이 문서는 15).
- 시안 생성 스크립트(좌표 계산 · 겹침 검사)는 세션 스크래치패드 `isilon-viz/{layout,sankey,orbit}.mjs` 에 있고 저장소에는 넣지 않았다(가상 데이터 전용).

## 7. 구현 결과 (v2.957 · ① + ③)

- 노드 부하 구역 ‘보기’ 에 **‘연결 그래프’** 한 칸(클라이언트 분포 옆) — 안에서 ‘모양’ 으로 **현 그래프 ↔ 노드 카드** 전환. 파일: `web/src/views/tools/storageNodeLoad/{nodeLoadViz.js,NodeGraphView.jsx}` + `nodeLoad.css` · 연결 `NodeLoadPanel.jsx` · 드로어 줄 강조 `NodeClientsDrawer.jsx`(`focus`).
  회귀: `nodeLoadViz.test.js`(좌표 · 순서 · 색 · 카드 · 상한) · `nodeGraphView.test.jsx`(SSR 스모크 · 폴링 없음 스윕). 서버 변경 없음(응답이 이미 있었다).
- 시안과 다른 점(정직 표기): ① 클라이언트 라벨은 **ops 상위 24개만**(나머지 툴팁 · 드로어) — 바닥 호 길이(≈13px)보다 글자가 커 22개부터 겹쳤다(Chromium 판독). ③ 칩 크기 3단계는 시안의 절대값(1,000 · 500)이 아니라 **가장 큰 클라이언트 대비**(60% · 25%) —
