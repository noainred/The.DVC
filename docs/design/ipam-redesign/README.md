## 3. 시안(아트보드 8장)

**이름 · 수치는 전부 가상**이다(VC-KR1 · web-kr1-023 · 7XK2M93 …). 색 · 글자는 `web/src/styles.css` `:root` 토큰 그대로(새 hex 없음), 이모지 아이콘은 쓰지 않았다.
계정의 'Design System' 아티팩트에는 `project/` 파일이 없어(파일 목록으로 확인) 쓰지 않았다.

| 보드 | 파일 | 내용 |
|---|---|---|
| ① | `Main.dc.html` | **현황** — 큰 검색 한 줄(IP · 이름 · 대역) · 타일 4장 · 조치 필요 목록(충돌 · 중복 · 예약 만료) · 여유가 적은 대역 · 점검 항목 · 법인별 표 |
| ② | `Subnets.dc.html` | **대역(주소 맵)** — 왼쪽 대역 목록(사용률 막대 · 검색 · 정렬) + 오른쪽 16×16 주소 맵(칸 하나 = 주소 하나) · 고른 주소 요약 · 이 대역의 정책 · 빈 주소 줄 |
| ③ | `Ledger.dc.html` | **대역(IP 대장 표)** — 주소 순 표: 주소 · 상태 · 호스트명/자원(+ DNS 불일치 표시) · **용도 · 요청자 · 할당자** · 관리 · 사용 이력 · **메모** · 연속된 예약/DHCP/빈 주소는 한 줄로 묶기 · 문제 행 바로 가기 |
| ④ | `Addresses.dc.html` | **IP 주소** — 필터 한 줄(상태 · 문제 · 출처 · 공인/사설 · 관리) + 표 6열 + 오른쪽 **상세 창 하나**(문제 설명 · 소유 자원 · 관리 편집 · 사용 이력) |

| ⑦ | `Settings.dc.html` | **설정**(관리자) — 숨길 대역 · 공인/사설 분류 · 가져오기/내보내기 · 공유 DB |

## 4. 새로 필요한 데이터(구현 전 확인 항목)

| 항목 | 지금 | 필요한 것 |
|---|---|---|
| 요청자 · 할당자 | 없음 | `overrides` 에 필드 2개 추가 + 관리 정보 CSV · 엑셀 · 공유 DB(ipam.db) 열. ⚠ ipam.db 는 외부 리더 계약이 있다(v2.619) — 열 추가가 리더를 깨지 않는지 확인 |
| 용도(사람이 넣는 값) | 자동 값뿐 | 새 필드로 둘지 기존 `label` 을 쓸지 결정 필요. 자동 값(정책 라벨 등)은 값이 비었을 때의 기본 표시로 |
| 이름 ↔ DNS 확인 | 스캔의 PTR 조회만 있음 | 판정 모듈 하나(서버) — 견줄 '설정한 이름' 의 우선순위(직접 넣은 호스트명 > 게스트 호스트명 > VM/호스트 이름), 비교 규칙(첫 마디 · 대소문자 무시)을 정한다. 정방향(A) 조회까지 할지는 결정 필요. 조회는 **법인 엣지가 자기 DNS 로**(중앙은 법인 내부 DNS 를 못 본다 · WAN 왕복 금지) |
| 서버 ↔ IP 묶기 | 서비스 태그 · iDRAC 맞추기는 있음 | 호스트 vmk 전체 IP 파싱(이미 받는 `config.network.vnic` — vCenter 왕복 0) · 서비스 태그 → {iDRAC IP · vmk IP · 그 호스트의 VM IP} 색인. 베어메탈(비가상화)은 iDRAC 등록부 + 스캔/수동 등록으로 묶는다(OS NIC IP 를 아는 출처가 있는지 확인 필요) |
| 못 읽은 값 | — | 서비스 태그 · DNS 결과를 못 읽은 것은 '일치' 도 '불일치' 도 아니다 — 따로 센다(`numOrNull` 규약과 같은 판단) |

## 5. 컨펌 받을 것

1. 탭 5개 구성과 이름(현황 · 대역 · IP 주소 · 스캔 · 설정)
2. 대장 기본 열(보드 ③) — OS · 확인 방식 · 마지막 확인을 기본에서 숨기는 것
3. 용도: 새 필드 / 기존 `label` 재사용
4. DNS 확인 범위: 역방향(PTR)만 / 정방향(A)까지
5. 서버 보기에 VM IP 를 함께 보일지(보드 ⑤ 아래 표)
6. 구현 순서(한 번에 / 단계 릴리스)

## 6. 검증 메모

- 현재 화면은 목 서버(v2.914.0 · `DATA_SOURCE=mock`)를 띄워 Chromium 1440px 로 6개 페이지를 캡처해 확인했다(`list` · `sheet` · `scan` 은 직접 판독).
- **시안 캔버스는 렌더 결과를 확인하지 못했다** — 아티팩트는 비공개라 이 컨테이너의 Chromium 으로 열 수 없다. 높이는 추정값이라 아래가 비거나 넘칠 수 있다.
