지금 있는 정방향 확인과의 관계

v2.993 은 물리서버 등록부의 이름을 DNS 에 물어 그 IP 가 나오면 이름을 붙입니다(‘정방향 DNS’ · ‘정방향 DNS 일치’ · ‘이름이 서로 다름’ 배지). 이번 것은 반대로 역DNS 가 답한 이름을 다시 묻습니다. 묻는 함수 · 시한 · 동시 수 · 차단기는 그대로 쓰고, 배지는 겹치지 않게 둘을 한 자리에서 정합니다(구현 때 표로 고정).

비용과 순서

이름 확인 단계 뒤, 물리서버 이름을 먼저 묻고 남은 예산으로 역DNS 이름을 묻습니다. 한 번 확인한 결과는 하루 동안 다시 쓰고, 오래된 것부터 묻습니다. 예산을 넘긴 이름은 ‘확인 못 함’ 으로 남고 다음 스캔이 이어 갑니다. 묻는 곳은 스캔을 돌린 쪽(법인 엣지 → 법인 DNS)입니다.

알지 못하는 것

스캐너가 쓰는 DNS 의 답입니다 — 안팎이 다른 DNS(분할 DNS)에서는 다른 곳의 답과 다를 수 있습니다. 운영체제 이름 풀이를 쓰므로 hosts 파일의 항목도 답에 섞입니다. NetBIOS · mDNS 이름이 DNS 에 등록돼 있는지는 도메인 접미사를 알아야 해서 기본 범위에서 뺐습니다(컨펌 질문).
