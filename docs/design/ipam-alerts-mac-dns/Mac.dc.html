같은 MAC 의 다른 IP (1개)
MAC 을 아는 방법 두 가지 — ‘ARP’ 는 스캐너가 같은 서브넷 IP 와 통신하며 운영체제 이웃 표에 남은 값(새 트래픽 없음), ‘NetBIOS’ 는 Windows · Samba 가 답한 값입니다. 둘 다 있으면 ARP 를 표시합니다.
제조사 — MAC 앞 3바이트를 등록 목록과 대조합니다. 목록에 없으면 ‘제조사 미상’, 임의로 지정된 MAC(가상 · 사생활 보호 MAC)은 ‘임의 지정 MAC’ 이라고만 적습니다.
가상 NIC — VMware · Hyper-V 같은 가상 NIC 대역의 MAC 인데 vCenter 가 모르는 IP 면 ‘미등록 가상 NIC’ 으로 모아 봅니다(등록되지 않은 ESXi · 다른 가상화의 VM 일 수 있음 — 단정하지 않습니다).
다른 서브넷 — 라우터 너머 IP 는 ARP 로 MAC 을 알 수 없습니다. NetBIOS 가 답한 MAC 이 없으면 ‘—’ 입니다(보드 ⑥).
VM · 호스트 행 — 제조사 · MAC 칸에는 스캔이 본 값을 그대로 적습니다. VM 행은 vCenter 가 아는 NIC MAC 과 다르면 보드 ⑤의 ‘충돌 의심’ 입니다. 호스트 행은 대조하지 않습니다(관리 IP 의 vmkernel MAC 은 수집에 없음).
