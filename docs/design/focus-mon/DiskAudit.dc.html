포탈은 이 고정 명령만 부르고, root 로 돌 코드를 보내지 않습니다. 실행 전마다 일반 계정으로 두 파일의 sha256 을 읽어 포탈이 아는 판본과 다르면 실행하지 않고 ‘판본 다름’ 으로 알립니다. python3 가 없는 서버(RHEL 7 은 기본 설치가 아닙니다)는 ‘python3 없음’ 으로 표시합니다.

실행 규칙 · 밝혀 둘 것

  • 그 서버를 맡은 노드(중앙 · 법인 엣지)가 실행합니다. 엣지는 결과를 정제된 요약과 보고서로 중앙에 올립니다 — 로그 원본을 WAN 으로 끌어오지 않습니다.
  • 노드마다 한 번에 {{ limNode }}대 · 서버당 시한 {{ limMin }}분 · 같은 서버는 {{ limGap }}분에 한 번. 시한을 넘기면 끊고 ‘시한 초과 — 일부만’ 으로 남깁니다.
  • 프로그램은 journal 전체와 회전된 messages 파일을 모두 읽습니다. 걸리는 시간과 부하는 로그 크기에 비례하고(실서버에서 재지 못했습니다), 낮은 우선순위(nice · ionice)로 돌립니다.
  • 실행은 수집 시작과 같은 권한(관리자 · 전체 쓰기 범위)이고 감사 로그에 남습니다. 결과에는 커널 로그 줄 · 디스크 시리얼이 들어 있어 이 탭은 관리자 · 전체 범위만 봅니다.
  • 로그에 남은 글자는 서버의 일반 사용자도 쓸 수 있습니다(예: logger). 그래서 화면은 ‘기록이 있다’ 고만 말하고, 고장을 단정하지 않습니다.
  • 대상 서버에 보고서 파일을 남기지 않습니다(임시 폴더에서 돌리고 지웁니다). 결과는 포탈에 서버마다 최근 {{ limKeep }}회 · {{ limDays }}일 보관합니다.
