노드별 SSH 공개키

개인키는 각 노드의 설정 폴더에만 있고 화면 · API · 백업에 실리지 않습니다. 서버에는 그 서버를 맡은 노드의 공개키 하나만 넣으면 됩니다.

이 엣지에 서버를 처음 등록하면 엣지가 키를 만들어 공개키를 올립니다. 엣지가 옛 판이면 ‘업그레이드 필요’ 로 보입니다.

대상 서버에 넣는 방법 — 엣지 PL-WRO 의 키

# 대상 서버에서 root 로 한 번만 (계정 이름은 예시)
useradd -m dvcmon
install -d -m 700 -o dvcmon -g dvcmon ~dvcmon/.ssh
cat >> ~dvcmon/.ssh/authorized_keys <<'EOF'
from="10.48.1.10",restrict ecdsa-sha2-nistp256 AAAAE2Vj…(생략)… dvc-focusmon@pl-wro
EOF
chown dvcmon:dvcmon ~dvcmon/.ssh/authorized_keys
chmod 600 ~dvcmon/.ssh/authorized_keys
restorecon -R ~dvcmon/.ssh
from= 은 그 노드 주소에서 온 접속만 이 키를 쓰게 하고, restrict 는 포워딩과 터미널 할당을 끕니다(OpenSSH 7.2 이상 — RHEL 7.8 은 7.4). 수집은 /proc 과 /sys 를 읽기만 하므로 root · sudo 가 필요 없습니다.
