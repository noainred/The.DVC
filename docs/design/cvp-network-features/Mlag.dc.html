문제 있는 것이 위로 옵니다. 멤버 상태를 못 읽은 포트 채널은 ‘정상’ 이 아니라 ‘확인 불가’ 로 따로 셉니다(지금 3개).
· ‘이중화 상실’ 은 지금 통신은 되지만 한 줄만 남은 상태입니다. 기존 장애 화면은 ‘관리상 켜져 있는데 내려간 포트’ 로만 잡으므로 이것을 따로 보여 줍니다.
· 의도적으로 한 줄만 쓰는 포트 채널은 ‘멤버 1개로 설정됨’ 으로 구분합니다(설정된 멤버 수 기준 — 올라온 수가 아님).
· MLAG 설정 정합성(양쪽 VLAN · 포트 채널 설정이 같은가)은 장비가 스스로 계산한 값을 읽습니다. 못 읽으면 판정하지 않습니다.
· 새 장애 종류로 열면 알림 · 닫는 규칙은 기존 부품 장애와 같은 규칙을 씁니다(판정은 중앙에서만).
