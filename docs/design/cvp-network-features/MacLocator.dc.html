· 위치는 ‘가장자리 포트’(상대가 스위치가 아닌 포트)에서 본 것만 답으로 씁니다. 업링크에서도 같은 MAC 이 보이지만 그건 지나가는 길이라 뺍니다.
· VM 은 호스트의 NIC 뒤에 있으므로 답은 ‘그 호스트가 꽂힌 포트’ 입니다. VM 이 어느 호스트에 있는지는 vCenter 인벤토리로 맞춥니다.
· MAC 표는 장비가 잠깐 기억하는 값입니다. 꺼져 있는 장비는 지금은 안 보이고 ‘마지막으로 본 시각’ 만 남습니다 — 없다는 뜻이 아닙니다.
· 저장량을 줄이려고 가장자리 포트의 MAC 만 저장하고 포트당 개수에 상한을 둡니다. 상한을 넘긴 포트는 ‘일부만 저장’ 으로 표시합니다.
