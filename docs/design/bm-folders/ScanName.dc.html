이름을 찾는 방법

역방향 DNS 지금 있음

IP 로 이름을 묻는다. 그 기록을 등록해 둔 IP 만 이름이 나온다.

정방향 DNS 새로

물리서버의 호스트 이름(iDRAC 이 읽은 이름)을 DNS 에 물어 IP 를 받는다. 스캔 대역 안의 IP 만 채택한다. 계정 없이 OS 주소를 찾는 핵심 방법.

인증서 이름 새로

443 이 열린 IP 의 인증서에 적힌 이름을 읽는다. 로그인하지 않는다. 주로 iDRAC · 웹 서버의 이름이 나온다.

SSH 접속 뒤 확인 새로

OS 계정이 이미 등록된 서버만 접속해 이름을 확인한다. 모르는 IP 에 로그인을 시도하지 않는다(계정 잠금 방지).

찾는 일은 스캔을 맡은 쪽(법인 엣지)이 그 법인 안에서 한다 — 이름과 방법만 중앙에 올린다.
