· 연결 장비는 포트 설명(주석)과 LLDP 이웃, 두 가지로 판단합니다. 둘이 같으면 ‘일치’, 다르면 LLDP 쪽을 표시하고 ‘불일치’ 로 알립니다.
· LLDP 를 보내지 않는 상대(일부 스토리지 · LLDP 를 끈 서버)는 이웃이 비어 ‘설명만’ 이 됩니다 — 설명에 적힌 이름일 뿐 실제 연결을 확인한 것이 아닙니다.
· 예비 = 링크 없음 + 설명 없음 + 관리상 켜짐. 설명이 있는 링크 없는 포트는 예비가 아니라 ‘확인 필요’ 로, 관리상 꺼진 포트도 따로 셉니다.
· 구성도의 블록 순서(1–24 · 49–56 · 25–48)와 후면 관리 포트는 이 모델의 실물 배치입니다. 색 띠는 실물의 포트 번호 띠(SFP 청록 · QSFP 보라)를 따랐습니다.
· 못 읽은 값은 0 이나 ‘없음’ 으로 쓰지 않고 ‘확인 불가’ 로 따로 셉니다(이 장비는 0개).
