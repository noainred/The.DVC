PL-WAW 수집 타임아웃 대응

Kkim 이 2026-11-04 09:41 에 고침 · 만든 사람 lee · 2026-10-29 ·라벨vcenter수집pl-waw

요약

폴란드 법인 vCenter 는 RTT 가 800ms 를 넘어 기본 수집 시한(60초) 안에 호스트 658대 인벤토리를 다 받지 못하는 날이 있다. 이 문서는 증상 → 확인 → 시한 조정 → 재발 방지 순서의 대응 절차다. 진행 중인 이슈는 ISS-1vCenter PL-WAW 수집 타임아웃 간헐 발생 이고, 상위 에픽은 ISS-20고RTT 법인 수집 안정화 다.

1. 증상

  • Overview 의 vCenter 카드가 timeout 으로 바뀌고 10분 뒤 자동 복구된다(간헐).
  • 엣지 로그 collect.inventory 에 deadline exceeded after 60.0s 가 하루 2~5회.

2. 확인

볼 곳정상이상
설정 › 수집 서버 › pl-waw · 지연650~820ms1,100ms 이상이 10분 넘게
특수 기능 › 통신 점검5단계 전부 OKTLS 단계만 2초 이상
엣지 상태 export마지막 보고 5분 안보고 없음(무음)

3. 시한 조정(런북)

vmware-portal-config set collect.deadlineMs 90000 --vcenter vc-pl-waw
systemctl restart vmware-portal-edge

바꾼 뒤 ISS-18시한 90초 적용 결과 확인 에 결과를 남긴다. 시한은 법인 단위라 다른 법인에는 영향이 없다.

4. 재발 방지

  • 수집 분할(호스트 300대 단위) — 변경 계획 [변경 계획] 수집 분할 참조(초안).
  • 이 문서를 고치면 관련 이슈의 ‘관련 문서’ 에 자동으로 보인다 — 따로 붙일 필요가 없다.
