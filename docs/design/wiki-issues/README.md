## 4. 설계 결정(시안에 그대로 그린 것)

### 4.1 위키
- **저장소**: `wiki.json`(스페이스 · 페이지 트리 · 메타) + 페이지마다 판 파일(`wiki/<pageId>/v<n>.md`) — 판은 지우지 않는다(상한 200판, 넘치면 중간 판을 접는다). 게시판과 같은 디바운스 원자 쓰기 · 손상 보존. 합계 상한 env(추정 64MB — 구현 때 정한다).
- **스페이스 = 공용 + 법인(vCenter)마다 하나.** 범위 계정은 자기 법인 스페이스 + 공용만 본다. 쓰기는 운영자 · 관리자, 댓글은 요청 권한(`issues.request`) 계정도. 스페이스 단위 '읽기 전용' 스위치.
- **본문은 마크다운**, 렌더러는 새로 둔다(기존 `BoldText` 는 `**강조**` 만) — 제목 · 목록 · 체크리스트 · 표 · 코드 · 인용 · 링크 · 그림 + 확장(콜아웃 `:::info|warn|danger|tip` · 접기 `:::fold` · 각주 · 목차 `[[toc]]` · 페이지 링크 `[[경로]]` · 포함 `{{include}}` · 포탈 매크로 `{{…}}`). **HTML 은 통째로 이스케이프**(sanitize — 스크립트 · 이벤트 속성 · `javascript:` 링크 금지). 의존성(markdown 파서)을 더할지, 작은 자체 파서로 갈지는 구현 때 결정 — 수식 · 머메이드는 이번 범위 밖.
- **ISS-n 자동 링크 + 역참조 색인**: 저장 때 본문 · 댓글의 키를 뽑아 `pageId → [keys]` 로 색인하고 이슈 상세가 `key → pages` 로 읽는다(범위 밖 페이지는 이슈 쪽에서도 숨긴다). 배지의 점은 이슈 상태색.
- **버전**: 저장마다 판 · 메모 · 상태(초안/검토 중/검토 완료/보관). 되돌리기는 새 판(메모 'vN 로 되돌림'). **충돌**: 편집 시작 판(`baseVersion`)을 저장 요청에 싣고 서버가 최신과 다르면 409 + 비교 화면(남의 저장을 조용히 덮어쓰지 않는다). 체크리스트 토글 · 인라인 댓글 해결은 판을 만들지 않고 이력 한 줄.
- **템플릿**: 내장 4(장애 보고서 · 런북 · 회의록 · 변경 계획) + 관리자 추가(마크다운 그대로, `wiki-templates.json`). `{{issue}}` 자리는 관련 이슈 값으로 채운다.
- **댓글 · @멘션 · 지켜보기**: 이슈 알림 모듈의 묶음 · 범위 거르기 · 멘션 해석을 그대로 재사용(새 메일 종류 'wiki' — 설정 › 메일 발송에서 끌 수 있음). 인라인 댓글은 본문 위치(앵커 텍스트 + 오프셋)를 저장하고 못 찾으면 페이지 댓글로 내린다.
- **포탈 매크로**: 열 때마다 API 로 읽는다(저장된 글이 아니다). 범위 밖 법인은 ‘볼 수 없는 법인’ 으로 비운다. PDF · 마크다운 내보내기에는 그 시각 값이 굳어 들어간다. 매크로 결과는 사용자 입력이 아니라 포탈 값이지만 역시 이스케이프해 싣는다.
- **검색**: 제목 · 본문 · 댓글 부분 문자열(대소문자 무시) · 스페이스 · 라벨 · 관련 이슈 · 상태 필터. 페이지 2,000 · 본문 64KB 상한이라 메모리 색인으로 충분하다고 **추정**(구현 때 2,000 × 64KB 로 실측 — 넘기면 SQLite FTS).

### 4.2 이슈 확장
- **계층 두 단계**: 유형 `epic` 추가 · `parentKey`(하위 작업 → 이슈, 이슈 → 에픽). 하위 작업에는 하위 없음. 에픽은 같은 법인(또는 공용) 이슈만. 이슈 진행률은 하위 작업이 있으면 **하위 완료 비율로 자동**(직접 입력 잠김) · 에픽 진행률 = 소속 이슈 완료 비율. 하위가 남은 채 상위를 완료하면 묻는다.
- **스프린트**: `sprints.json`(이름 · 기간 · 목표 · 상태) · 이슈에 `sprintId`. 보드는 스프린트 범위 칸반(백로그 열 없음) + 백로그 서랍. 번다운은 이력(`closedAt` · 스프린트 넣기/빼기 이력)에서 계산 — 별도 적재 없음. 끝내기 = 미완료를 다음 스프린트/백로그로(이력에 남김). 스프린트 생성 · 끝내기는 전체 범위 운영자 · 관리자, 넣기/빼기는 쓰기 범위.
- **검색식**: 작은 파서(필드 · `= != in not in > >= < <= ~ is empty` · `me() now() active() -7d` · AND/OR/괄호 · ORDER BY) — **서버가 해석해 거른다**(화면 복제 금지, `listIssues` 위에 얹음). 범위는 식보다 먼저. 식 500자 · 조건 20개. 저장 필터 `issue-filters.json`(사람당 50 · 공유는 전체 범위 운영자). 주간 메일 구독은 월요일 09:00(포탈 날짜). 보드 · 목록 · 스프린트 · 위키 `{{issues}}` 매크로가 같은 식을 쓴다.
- **연결**: `links[]`(blocks/blockedBy/relates/duplicates — 양방향 저장) · '차단됨' 배지 · 완료 전 확인. **체크리스트**: 항목 배열(완료 비율을 진행률로 쓰는 스위치). **첨부**: `wiki-attachments/`·`issue-attachments/` 파일 저장(8MB · 20개 · 확장자 화이트리스트 · 저장 이름은 서버 발급). **시간 추적**: 예상 · 기록 배열. **SLA**: 우선순위별 목표(설정) · 대응/해결 시각 · 보류 중 정지 · 초과 알림 + 배지. **수정/영향 버전**: 포탈 release-notes 버전과 잇는다(게시되면 노트에 한 줄). **캘린더**: 기한 · 스프린트 기간 뷰(끌어 옮기기 → 이력).
- **마크다운**: 이슈 본문 · 댓글도 위키와 같은 렌더러.

### 4.3 파트 장애 → 이슈 자동 등록(⑪)
- **훅 자리**: 중앙이 엣지 전이를 받는 곳(`partfault` 전이 적용 직후 — 알림과 같은 자리). 파트 장애 기능이 켜진 법인만. 설정 파일 `issue-autocreate.json`(전체 범위 관리자만 저장 · 감사 로그).
- **무엇을**: 부품 종류(16) × 장비군(idrac · storage · sanswitch · esxi) 매트릭스, 칸마다 끔 / fault / fault+warn. 장비군이 그 부품을 보고하지 않는 칸은 ‘—’(추출기 없음 — 지어내지 않는다). PDU 는 대상이 아니다. `unknown` · `absent` 는 장애가 아니므로 등록하지 않는다. 종류마다 우선순위 기본값(디스크 · PSU · 메모리 P1, CPU · 컨트롤러 · 노드 P0, 팬 · NIC · 포트 P2, 기타 P3 — 설정에서 바꾼다). 법인별 예외(끔).
- **만드는 이슈**: 유형 장애 · 법인 = 그 엣지의 vCenter(1:1:1) · 컴포넌트 = 부품 종류 이름 → **기존 자동 할당 규칙**이 담당자를 정한다 · 에픽 · 라벨(`partfault, auto`) · 제목 틀(`[파트 장애] {법인} · {장비} · {부품종류} {부품} {상태}`) · 본문(장비 · 부품 · 키 신뢰도 · 처음 감지 · 파트 장애 화면 링크 · 라벨 `partfault` 위키 런북 링크). 이슈에 `origin: { kind: 'partfault', agent, partKey }` 를 남겨 화면이 '자동 등록' 배지를 단다.
- **중복 · 폭주**: 같은 (agent · partKey) 열린 이슈가 있으면 새 이슈 대신 댓글('다시 열림 N회째'). 한 장비에서 5분 안 5건 넘으면 장비 단위 1건(부품 목록은 본문). 하루 상한 50 — 넘으면 멈추고 상태에 '상한 도달'(조용히 버리지 않는다). 수치는 전부 설정.
- **장애가 바뀌면**: ok/removed 해소 → 댓글 + 상태 '검토'(완료는 사람이 — 설정으로 '그대로' 선택 가능) · manual → 댓글만 · 보류(unknown · 컬렉션 실패) → 댓글 '판정 보류', 닫지 않음. 이슈가 먼저 완료된 뒤 같은 파트가 다시 열리면 새 이슈(옛 이슈에 '연결: 관련').
- **알림 두 통 방지**: '파트 장애 자체 알림은 끄고 이슈 알림만' 토글(기본 끔 — 사용자가 고른 '파트당 1건 즉시' 를 바꾸지 않는다).
- **시험 실행**: 지난 24시간 전이에 설정을 대 보고 '이슈 N · 댓글 N · 건너뜀 N(사유별)' 만 보여 준다(만들지 않는다).
- **다른 알람**(vCenter 끊김 · 백업 실패 · 인증서 · 데이터스토어 · 엣지 무응답 · 리허설 실패)은 같은 훅 틀로 **다음 단계** — 이번 구현 범위에 넣지 않고 설정 화면에 '다음 단계' 로만 보인다.
- **자동화 규칙**: 고정 목록(완료 → 위키 체크 항목 완료 · 7일 멈춤 알림 · P0 즉시 채팅 + SLA · 하위 전부 완료 → 상위 검토)에서 켜고 끈다. 자유 스크립트 없음.
- **리포트**: 생성 · 해결 추세(주별) · 평균 해결(완료만 · 보류 제외) · 법인별 열린 이슈 · 담당자별 투입 시간 · SLA 준수율 · 자동 등록 비율 — 서버 집계 · CSV.
