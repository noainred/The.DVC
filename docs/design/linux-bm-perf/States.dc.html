⑥ 인증 정지 — 자동 재시도 없음

⑦ OS 만 — iDRAC 등록 없음

bm-us1-app07 은 OS(SSH) 로만 읽힙니다. CPU·메모리·디스크·네트워크 USE 와 튜닝·스냅샷은 있지만 온도·전력·부품·ECC·SMART 는 ‘경로 없음’ 이고 교차 판정은 꺼집니다. iDRAC 등록부에 이 서버(서비스 태그 7H2K3L9)를 추가하면 다음 주기부터 채워집니다.
‘경로 없음’ 은 못 읽음(missing)과 다른 칸이다 — 등록이 없으니 시도도 없었다. KPI ‘두 경로 다 읽힘’ 의 분모에는 들어가고 분자에는 안 들어간다.

⑨ 불일치 — 두 경로의 값이 어긋남

CPU 사용률이 두 경로에서 다릅니다 — OS 62% · iDRAC 31%

bm-pl1-db02 의 OS(/proc/stat) 와 iDRAC(SystemUsage CPUUsage) 값 차이가 31%p 입니다(기준 15%p · API 값). 화면은 OS 값을 쓰되 iDRAC 값을 곁에 적고 ‘불일치’ 로 표시합니다. 어느 쪽이 맞는지 단정하지 않습니다 — 샘플링 창이 다르거나(iDRAC 집계 주기) 텔레메트리 메트릭 id 가 다른 것일 수 있습니다. 첫 실수집에서 usedIds 를 보고 좁힙니다.
두 값을 평균내거나 한쪽을 조용히 버리지 않는다 — 두 화면의 숫자가 다른 이유를 사용자가 알아야 한다(기존 srcOf 규약의 확장).
