규칙 · 정직 기록

  • 비교는 같은 길이·같은 롤업으로만 한다. 길이가 다르면 짧은 쪽에 맞추고 화면이 말한다. 결측 점은 양쪽에서 빼고 개수를 적는다.
  • 변경 이벤트는 전이만 기록한다(5분마다 전체를 적지 않는다). 해시 비교라 ‘무엇이 바뀌었는지’ 는 sysctl 키·패키지 목록·cron 파일 이름까지만 알고 내용 diff 는 보관하지 않는다(설정 파일 내용은 포탈이 보관하지 않는다 — 비밀이 섞일 수 있다).
  • ‘영향 추정’ 은 시각 일치만 말한다. 원인 확정은 담당자가 하고, 이슈에 첨부할 수 있다.
  • dnf history · needs-restarting 는 Rocky 에 있지만 출력 형식은 실장비에서 확인하지 못했다(정직 기록) — 파서는 구획 표지·행 수 상한으로 보호한다.
