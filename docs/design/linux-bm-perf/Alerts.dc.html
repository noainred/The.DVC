규칙 · 정직 기록

  • 판정·베이스라인 계산은 엣지가 하고 알림 발송도 엣지가 한다(중앙 알림 설정을 엣지에 배포 — 베어메탈 사용률 설정 배포와 같은 길). 중앙은 발송 기록을 봉투로 받아 ‘알림 이력’ 에 보여 준다.
  • 이슈 자동 등록은 기존 문지기(관리자 + 전체 범위 · 하루 상한 · 법인 예외 · 시험 실행 = 지난 N시간에 대 보기, 만들지 않음)를 그대로 쓴다.
  • 베이스라인은 ‘지난 4주 같은 요일·시각’ 의 1시간 롤업 평균이다 — 휴일·월말 같은 달력 효과는 모른다(화면이 말한다). 4주 미만·결측 많음이면 걸지 않는다. ML 이상 탐지는 채택하지 않았다.
  • 알림 채널(메일·웹훅)은 기존 알림 설정의 것을 재사용하고 새 채널을 만들지 않는다. 웹훅 URL 은 비밀이라 화면에 싣지 않는다.
