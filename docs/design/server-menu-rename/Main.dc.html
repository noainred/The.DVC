바뀌는 이름

  • 1
    가상화 플랫폼 → Virtual Machine(VM)
    서버 그룹의 항목 이름. 누르면 가상화 서버(VM) 탭이 열립니다.
  • 2
    물리서버 폴더 → Bare Metal Server
    사이드바 항목과 특수 기능 카드 이름이 함께 바뀝니다.
  • 3
    Hypervisor새 항목
    가상화 플랫폼 안에만 있던 ESXi 호스트 탭으로 바로 가는 메뉴입니다.
  • 4
    서버 분석 → Physical Server
    특수 기능 카드와 자원관리 메뉴. 요청 원문 ‘Pysical’ 은 오타로 보고 Physical 로 적었습니다.

    서버 분석의 Baremetal 구분만 여는 바로가기입니다. 4번 뒤에는 Physical Server 와 뜻이 같은 이름이 됩니다.
