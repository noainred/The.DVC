🧩 서비스 맵 시안 A · 2차 · 목 데이터 관리자 판본

VM(vCenter)·베어메탈(iDRAC/OS)·ESXi 호스트를 법인 › 폴더 › 서비스 트리로 묶어 봅니다. 소속은 vSphere 태그 → iDRAC 스캔 엔트리 서비스명 → 수동 지정 → 이름 규칙 순으로 한 판정 코어가 정하고, 어디에도 안 걸리면 (미지정) 으로 따로 셉니다. iDRAC 에서 식별된 서버는 '서버 추가' 로 골라 서비스에 넣습니다(수동 지정 — 태그·스캔 라벨보다 우선, 감사 로그).
법인별 관리: 범위 계정은 자기 법인 노드만 보고, 쓰기 범위가 있는 법인 관리자는 자기 법인의 폴더·서비스·구성원을 바꿉니다. 태그 카테고리·이름 규칙 설정은 전체 범위 관리자만. 못 읽은 값은 '—'(0 아님)이고 합계에서 빠지며 개수로 밝힙니다.
