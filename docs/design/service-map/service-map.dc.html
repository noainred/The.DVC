VM(vCenter)·베어메탈(iDRAC/OS)·ESXi 호스트를 서비스 단위로 묶어 봅니다. 소속은 vSphere 태그 → iDRAC 스캔 엔트리 서비스명 → 수동 지정 → 이름 규칙 순으로 한 판정 코어가 정하고, 어디에도 안 걸리면 (미지정) 으로 따로 셉니다. 숫자는 모두 이미 수집된 스냅샷·캐시의 조인이라 vCenter·iDRAC 왕복이 없습니다.
못 읽은 값은 0 이 아니라 '—' 이고 합계에서 빠지며 못 읽음 열에 개수로 밝힙니다. 사용률 합산은 서버마다 사용률 × 용량(법인별 서버 사용량과 같은 규약)입니다. 갱신 시각·주기는 API 값(아래 각주).
