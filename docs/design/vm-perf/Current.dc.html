성능 모달에서 잘 안 되는 것(캡처 판독 + 코드)
  1. 버튼 10개가 한 줄 — 지표 4(CPU·메모리·디스크·네트워크)와 기간 5(실시간~년)가 같은 모양으로 섞여 있어 무엇이 축인지 읽기 어렵다.
  2. 기간 지정이 영문 로캘 datetime-local 두 칸(mm/dd/yyyy, --:-- --) — 날짜를 두 번 타이핑해야 과거를 볼 수 있고 ‘이전 24시간’ 같은 이동이 없다.
  3. 한 번에 한 지표 — CPU 를 보다 메모리를 보려면 다시 조회(로그인 1회 + QueryPerf 1회) · 최대 · 최저가 언제였는지 없다.
  4. 실시간 180점(20초)이 톱니 — 평균선 · 과부하 기준선이 없어 ‘높은가’ 를 눈으로 가늠한다. 일 평균은 X 축이 ‘오후 11:01’ 식.
  5. 모달 위 모달 — 드로어 · 개체 보기 위에 또 창이 떠서 주소가 없고(새로고침 · 공유 불가) 400px 에서 차트 높이 340 고정.
  6. 지표마다 로그인 — fetchEntityMetric 이 호출마다 login → QueryPerf → logout. 드로어 스파크(2회) + 모달(1회 × 20초) 이 겹치면 분당 로그인이 늘어난다(v2.591 계정 잠금 규칙의 경계).
