올린 사람 자신은 승인 단추가 잠깁니다. 설정 소유자가 한 명뿐인 포탈에서는 등록한 스크립트를 쓸 수 없습니다(포탈 묶음 스크립트만 실행).

새 스크립트 올리기 — 적는 것

설정 소유자 · 본인 OTP

바로 멈추기 · 지우기

사용 중지설정 소유자 한 명이 본인 OTP 로 즉시. 진행 중인 실행은 그 서버까지만 하고 멈춥니다. 다시 쓰려면 두 사람 승인을 다시 받습니다.
포탈 묶음포탈 릴리스에 들어 있는 스크립트는 여기서 고칠 수 없습니다. 릴리스 서명으로 확인하고, 파일이 서명과 다르면 실행하지 않습니다. 사용 중지는 할 수 있습니다.
백업 복원복원으로는 승인을 되살리지 않습니다 — 복원한 스크립트는 ‘승인 대기’ 로 돌아옵니다.
