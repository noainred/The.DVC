해석 순서(순수 함수 — 테스트가 고정)

1. 수동 매핑(이 화면) → 2. 이름 규칙(벤더::시리얼::디렉터 포트) → 3. 조닝 별칭(Unity_SPA0_p8 꼴의 SPA/SPB) → 4. '(구분 못 함)'.
분류도 같다: 수동 → 시리얼 일치(등록 스토리지) → 이름 규칙(`::`) → 호스트. 수동 값에는 근거 배지가 붙어 자동과 구분됩니다.

저장 규약

파일 CONFIG_DIR/san-storage-map.json — 관리자 전용 PUT · 원자 쓰기 · 손상 보존(preserveCorrupt) · 자격증명 아님(vault 대상 아님) · 감사 로그 '어레이 포트 디렉터 매핑 변경'. 키 = 어레이키|deviceId|port. SAN 은 vCenter 범위 밖이라 fullScopeOnly.
포트가 재배선돼 심볼릭 이름이 바뀌면 그 매핑은 '이름이 바뀜' 배지로 보이고 자동으로 지우지 않습니다.
