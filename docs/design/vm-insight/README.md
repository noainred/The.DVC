## 7. 구현 메모(컨펌 뒤 · Opus)

- **집계는 서버에서 한 번에**: 화면이 VM 5,850대를 받아 세면 안 된다. 새 응답(예: `/vms/insight`)이 법인별 줄(이 보드의 `rows()` 와 같은 모양 — 수 · 합 · 분포 배열)을 준다. 화면은 고른 법인의 줄을 더하기만 한다(복수 선택에 서버 왕복이 없다).
  상시 폴링 경로이므로 `memoJson` + `extraKey: scopeKey(...)`(+ 역할) · 큰 집계는 조각 + 시간 기준 양보(`createYielder`) — `docs/rules/perf-db.md`. 범위 계정은 조회 범위 안의 법인 줄만 받는다(교집합 먼저).
- **못 읽은 값은 0 이 아니다**: 사용률 미수집 VM 은 평균 · 히스토그램 · 유휴 판정에서 빼고 따로 센다(`util/numOrNull.js`). 엣지 위임 법인의 값이 늦으면 그 법인 줄에 ‘오래됨’ 을 표시하고 합에 섞지 않는다.
- 판정은 하나: 과부하 · Tools · 스냅샷은 지금 신호 판정(`signals`)을 그대로 쓴다. ‘유휴 후보’ 는 새 판정이라 서버 한 곳에 두고 테스트로 고정한다.
- OS 계열(Windows / Linux / 기타)은 `guestOS` 문자열에서 정한다 — 모르는 이름은 ‘기타’ 로 세고 0 으로 숨기지 않는다. OS 종류가 8개를 넘으면 뒤쪽을 ‘그 밖’ 으로 접는다.
- 화면: 보기 키 `insight` 를 `HUB_VIEWS` 맨 앞에(주소 `#/vms/insight` · 지금 `#/vms` 는 새 기본으로) — 저장된 주소 `#/vms/list` 는 그대로 열린다. 법인 지도의 칸 · 지역 줄 · 분포 칸을 누르면 바로가기 선택 또는 ‘목록’ 의 조건(지금 `facets`)으로 이어진다.
- 표가 아닌 목록 · 차트지만 ‘지금 볼 VM’ 은 `STable`(제목 클릭 정렬) · 문구에 백틱 금지 · 그리드 자식 `min-width:0` · Chromium 1440 · 400.
- **디스크 패널 · 과할당은 새 계산을 만들지 않는다** — `guestpart/report.js overview`(응답의 `kpi` · `vcenters[]` · `rows[]`)와 `/tools/waste`(`overAllocated` · `poweredOff` · `snapshots` · `thinReclaim` · `noTools` · `byVcenter[]`)를 그대로 쓴다. 판정을 화면에서 다시 하지 않는다(판정 코어는 하나).
  법인별 합이 필요한 값 중 응답에 없는 것 — 초과 파티션의 구간별 수 · OS 별 수 · ‘곧 가득’ 의 법인별 수(게스트 파티션) / CPU · 메모리의 법인별 할당 · 사용 · 미사용(Optimization 의 `byVcenter` 에는 후보 수만 있다) — 은 서버 응답에 더한다(화면이 줄 300개를 세지 않게 · `LIST_LIMIT` 에 잘린 목록으로 세면 틀린다).

- 링크: ‘모두 보기’ 는 `#/tools/guest-partition` · `#/tools/waste` 로 — 고른 법인이 한 곳이면 그 범위를 들고 간다.

- 구현 메모: `off-since` 는 DB 조회라 느릴 수 있다(도구도 목록을 먼저 그리고 이 값을 뒤이어 채운다) — 패널도 수 · 디스크를 먼저 그리고 꺼진 지를 나중에 채운다. `tools` 권한이 필요하다(§7 의 권한 메모와 같다). 꺼진 지를 못 찾은 VM 은 ‘모름’ 으로 세고 0일로 넣지 않는다.
