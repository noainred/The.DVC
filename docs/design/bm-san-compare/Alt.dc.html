좋은 점
  • 도구 키 · 권한 파일 · 카탈로그 변경 없음(기존 adminOnly · 전체 범위 그대로)
  • ‘지금 측정’ · 주기 · 서버 등록이 한 도구 안
  • 현황 탭의 12시간 이력 · 그룹 색을 같이 씀
아쉬운 점
  • SAN 스위치 · 스토리지 모니터링 화면에서는 링크로만 온다
  • SAN 쪽 사람은 ‘베어메탈’ 메뉴 아래를 찾아야 한다 — 특수 기능 카드 설명에 ‘SAN 비교’ 를 적어 검색에 걸리게

대안④-B 자리 — 새 특수 기능 ‘스토리지 비교’

스토리지 비교베어메탈 · SAN 어레이 용량 사용률 · 전송 속도 한 표 · 운영 작업
좋은 점
  • 양쪽 사람이 찾기 쉬운 이름 · 독립 주소
비용
  • 새 도구 키 + 권한 매트릭스 + 카탈로그(PRESET) + 서버 집행 매핑 + 사용 현황 집계 — 변경 파일 6곳 이상 · 권한 테스트 대조
  • ‘지금 측정’ 버튼이 두 화면에 생겨 재진입 가드 · 문구를 둘 다 맞춰야 함

추천④-C ‘실시간’ 의 뜻 — 주기 하한 1분 + ‘지금 측정’

수집 주기 1분 (현황 탭의 ✎ 으로 바꿈 · 1~1440분)
화면은 15초마다 가벼운 현황(메모리 값)만 다시 읽고, SSH 는 주기 · 버튼 때만 엽니다.
좋은 점
  • 지금 있는 주기 설정 그대로 — 새 상태 없음
  • SSH 부하가 사람이 정한 주기를 넘지 않는다(28법인 · 1,000대 상한)
  • 엣지 위임 서버도 같은 경로(잡 큐 · PUSH)
한계(화면이 말함)
  • ‘실시간’ 은 수집 주기 단위다 — 표본 시각을 행마다 표시
  • 엣지 폴링 위임은 회신까지 수십 초 더 걸린다

대안④-D 화면이 열려 있는 동안 자동 1분 측정

자동 측정 켬 · 이 화면을 보는 동안 1분마다 ‘지금 측정’ · 닫으면 멈춤
좋은 점
  • 버튼을 누르지 않아도 1분 값이 흐른다
위험
  • 화면을 여러 사람이 열면 서버마다 SSH 로그인이 겹친다(재진입 가드가 막아도 로그인 시도는 쌓임 — 계정 잠금 규칙과 충돌)
  • 수집 주기 설정과 두 번째 ‘주기’ 가 생긴다(판정 코어 둘)
  • 엣지 폴링 위임 서버에는 1분이 의미가 없다(회신 지연)
④-D 를 고르면 ‘자동 측정’ 은 서버가 관리자별 1건 · 최소 60초 · 5분 뒤 자동 꺼짐으로 묶고 감사 로그를 남기는 조건을 답니다. 기본 추천은 ④-A + ④-C.
