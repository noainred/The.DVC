▸ 숫자를 비교할 때 알아 둘 것
  • 용량의 뜻이 다릅니다. 베어메탈은 df 의 used / (used + avail)(지정 마운트만, ext4 예약 블록 제외). SAN 은 Unisphere 가 보고한 데이터 감축 후 실사용(usable_used_tb)이며 호스트에 약속한 씬 구독량이 아닙니다.
  • 전송 속도의 출처가 다릅니다. 베어메탈은 서버에서 /proc/diskstats 를 2초 간격 두 번 읽은 그 순간의 표본(서버 전체 물리 디스크 합 — 마운트별이 아님). SAN 은 SAN 스위치 포트 트래픽을 어레이 시리얼로 묶은 1시간 평균(또는 피크)이고, 어레이 자체 성능 API 는 수집하지 않습니다.
  • 시각이 다릅니다. 베어메탈은 수집 주기(기본 10분, 최소 1분)마다, ‘지금 측정’ 을 누르면 즉시 다시 잽니다. SAN 포트 표본은 5분 주기, 용량 스냅샷은 60분 주기입니다. 표의 ‘측정 기준’ 열이 각 값의 시각을 말합니다.
  • 못 읽은 값은 0 이 아닙니다. 측정 불가 서버·시리얼 미대조 어레이는 ‘—’ 로 두고 합에서 빼며 몇 대가 빠졌는지 씁니다. 부분 합은 호박색입니다.
