SSH 공용 접속 · 키 폴더

인증키를 법인 폴더 아래 ‘공통’ 과 ‘서버별’ 로 나눠 둡니다. 화면에서 만들거나 올릴 수 있고, 서버에서 폴더에 직접 넣은 파일도 여기 나타납니다.

폴더

ssh-keys/
미국 동부1 공통1 서버별0 베트남0 인도0 폴란드4 공통2 서버별2 pl-gpu-011 pl-db-031 한국 본사1 공통1 서버별0
숫자는 키 개수입니다. 키가 없는 법인은 비밀번호로 접속하거나 아직 설정하지 않은 곳입니다.

폴란드

있는 곳엣지 pl-edge — 이 법인의 키는 그 법인 안에만 둡니다. 중앙은 목록과 지문만 받아 보여 줍니다.
경로<포탈 설정 폴더>/ssh-keys/pl/
권한폴더 0700 · 파일 0600 · 포탈 실행 계정 소유. 다르면 그 키를 쓰지 않고 이유를 적습니다.

서버별 2개

ssh-keys/pl/servers/<서버>/
서버 폴더 ▴이름종류지문상태계정동작
pl-db-03/id_ed25519ed25519SHA256:c7Rt1b…Xq9d 쓰지 않음
이 서버는 법인 공통으로 접속
root
pl-gpu-01/id_ed25519ed25519SHA256:Ae41Zp…m0Vk 사용 중svc-mon
어느 키로 접속하나: 서버별 폴더의 키 → 법인 공통 키. 서버 폴더 이름은 SSH 공용 접속에 등록한 서버 이름과 같아야 합니다. 폴더에 직접 넣은 키는 관리자가 ‘승인’ 하기 전에는 쓰지 않습니다 — 누가 넣었는지 포탈이 알 수 없기 때문입니다. 개인키는 화면에 보이지 않고 내려받을 수 없습니다(지문 · 공개키만). 쓰고 있는 키는 지울 수 없습니다 — 먼저 교체합니다. 암호(passphrase)가 걸린 키는 가져올 때 한 번 묻고, 풀어서 포탈의 암호화 보관 방식으로 다시 저장합니다.
