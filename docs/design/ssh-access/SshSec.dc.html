SSH 공용 접속 · 키 보안

로그인 키 하나가 그 법인의 서버 전부를 엽니다. 그래서 키는 다른 비밀번호보다 엄하게 다룹니다 — 항상 암호화해 두고, 바꾸는 일은 OTP 와 두 사람의 승인을 거치며, 누가 언제 어디에 썼는지 남기고, 이상하면 바로 멈춥니다.

보호 장치

전 법인 공통 설정 · 바꾸려면 OTP
항상 켬개인키는 항상 암호화포탈의 비밀 저장 방식이 ‘평문’ 이어도 로그인 키는 암호화합니다. 화면 · 응답 · 로그 · 내려받기로 내보내지 않습니다.
항상 켬키 작업은 본인 OTP만들기 · 가져오기 · 승인 · 교체 · 삭제 · 서버에 넣기 · 이 화면의 설정 변경.
두 사람 승인키 만들기 · 교체 · 삭제 · 승인은 다른 관리자 1명이 승인해야 실행됩니다. 요청은 24시간 뒤 사라집니다.
서버 쪽 제한서버에 넣는 키 줄에 ‘이 엣지 주소에서 올 때만’ · ‘포워딩 금지’ 를 붙입니다 — 키가 새도 다른 곳에서는 쓸 수 없습니다.
쓸 수 있는 기능만키마다 허용한 기능만 그 키로 접속합니다 — 폴란드 공통: 디스크 점검 · 스토리지 · 사용률 · Bareos 설정. 자유 명령 실행 경로는 없습니다.
교체 기준 180일넘으면 ‘교체 권고’ 를 띄우고 알립니다. 교체는 새 키 접속을 확인한 뒤에만 옛 키 줄을 지웁니다.
알림키가 바뀜 · 폴더에 새 파일 · 지문/권한 이상 · 로그인 실패 · 처음 보는 서버나 기능에서 사용 — 보안 담당 메일로.
포탈 백업에 키 넣기꺼 두면 백업 파일에 키가 없습니다 — 복구한 뒤 키를 새로 만들어 다시 넣어야 합니다.
잠금 해제 방식켜면 포탈이 다시 시작할 때마다 관리자가 암호를 넣어야 키를 씁니다. 서버가 통째로 넘어가도 키는 열리지 않지만, 넣기 전까지 SSH 수집이 모두 멈춥니다.

긴급 조치 — 폴란드

키가 샜다고 의심될 때 · OTP 필요 · 두 사람 승인 없이 바로 실행(멈추는 방향)
지금부터 포탈 · 엣지가 이 법인의 키로 접속하지 않습니다. 서버는 바꾸지 않습니다. 다시 켜려면 두 사람 승인.
서버마다 포탈이 넣은 키 줄을 지웁니다. 닿지 못한 서버는 목록으로 남겨 사람이 지우게 합니다.
새 키를 만들어 넣고 확인한 뒤 옛 키 줄을 지웁니다. 옛 키 파일은 지우고 지문만 기록에 남깁니다.
