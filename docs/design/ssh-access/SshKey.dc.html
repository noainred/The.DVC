서버에 공개키 한 줄을 넣어, 다음부터 비밀번호 없이 접속하게 합니다.

등록에 쓸 비밀번호
하는 일
  1. 비밀번호로 한 번 접속합니다.
  2. ~/.ssh/authorized_keys 끝에 공개키 한 줄을 더합니다 — 포탈이 넣은 줄임을 알 수 있게 표식을 붙입니다.
  3. 접속을 끊고 키로 다시 접속해 확인합니다.
  4. 확인되면 ‘키 로그인 됨’ 으로 기록합니다.
잘 안 되면키 접속이 확인되지 않으면 더한 줄을 지우고 원래대로 둡니다. 비밀번호가 틀리면 다시 시도하지 않습니다(계정 잠금 방지).
선택
바꾸지 않는 것sshd 설정(비밀번호 로그인 허용 여부 등) · sudoers · 다른 사람이 넣은 키 줄.
