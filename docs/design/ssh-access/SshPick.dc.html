어느 키로 접속하나 — 위에서부터

1서버에 이름으로 고정한 키 — 이 창에서 고른 것. 공통 폴더의 키든 서버별 폴더의 키든 이름으로 가리킵니다.
2법인 기본 키 — ‘법인 기본 키를 따름’ 인 서버. 키 폴더에서 공통 키 하나를 기본으로 정합니다.
3없음 — 키가 없으면 저장된 비밀번호, 그것도 없으면 접속하지 않고 ‘미설정’.
고정한 키가 폴더에서 사라지거나 지문이 달라지면 다른 키로 넘어가지 않고 멈춥니다 — 조용히 다른 키를 쓰지 않습니다. 여러 서버를 골라 같은 이름의 키를 한 번에 지정할 수 있습니다(서버 표의 체크 상자 → ‘선택한 서버 키 고르기’). 서버마다 ‘들어 있음 / 없음’ 을 따로 보여 줍니다.
