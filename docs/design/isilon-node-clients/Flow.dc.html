장비 부담 산수(5분) 클러스터 1개 — REST 호출 4 × 12/시간 = 48회/시간 · SSH 로그인 12회/시간(세션 1 · 명령 4) 법인 28개 — REST 1,344회/시간 · SSH 라면 로그인 8,064/일 → 장비 감사 로그가 그만큼 늘어납니다. 모두 ‘표본 조회’ 뿐이고 쓰기는 없습니다. 15분으로 바꾸면 1/3. 끄는 것은 장비별 토글.
행 수 산수(클러스터 1개 · 8 노드) 노드 원시 8 × 288 = 2,304행/일 → 7일 1.6만 · 시간 요약 8 × 24 = 192/일 → 90일 1.7만 · 일 요약 8/일 클라이언트 원시 8 × 10 × 288 = 23,040행/일 → 2일 4.6만 · 시간 요약 ≤ 8 × 10 × 24 = 1,920/일 → 30일 5.8만 · 일 요약 ≤ 80/일 → 1년 2.9만 64 노드면 8배. 전부 ts·day 인덱스 + 청크 삭제 + 트랜잭션 — 기존 규약.
push 크기 산수(엣지 → 중앙) 표본 1개 ≈ 노드 64 × (지표 9 + 클라이언트 10 × 7필드) ≈ 64 × 0.9 KB ≈ 58 KB · 고리 3개 ≈ 170 KB · gzip 뒤 약 1/5 장비당 상한 1 MB(기존) 안. 클라이언트를 20으로 올리면 두 배 — 상한 N 은 설정값으로 두고 기본 10.
클라이언트 없음‘연결 없음’ 이 아니라 최근 작업한 클라이언트 없음. 쉬는 마운트는 통계에 없다고 문장으로 말합니다.
SSH JSON 미확인세 모양을 받고 못 읽으면 노드 수집 상태에 ‘client 명령 출력 형식 불명’ + 받은 키. 네트워크·CPU 는 그대로.
이름 못 찾음인벤토리(VM IP · 호스트 관리 IP · IP 대장)에 없으면 IP 만. 역방향 DNS 는 하지 않습니다(SSRF·지연).
표본 늦음마지막 표본이 주기의 3배를 넘으면 드로어 머리에 ‘마지막 표본 N분 전’ 을 노랗게. 엣지는 push 지연까지 더해 봅니다.
수집 꺼짐토글을 끈 장비는 묶음 버튼이 1시간 표본으로 그려지고, 드로어는 ‘표본 수집이 꺼져 있습니다(장비 편집)’ 를 말합니다.
