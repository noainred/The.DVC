서버 명령 실행 — 정해 둔 명령을 골라 서버에서 돌리고 출력을 받는다

이미 만든 접속 코어(계정 고르기 · 잠금 방지 · 시한 · 출력 상한)를 그대로 쓰고, 그 위에 ‘프리셋 목록’ 과 ‘출력 보여 주기’ 만 얹습니다. 화면에서 명령 글자를 직접 넣는 길은 만들지 않습니다.

별도 특수 기능으로 둔다

‘서버 정보’ 와 같은 자리(특수 기능 › 서버)에 화면 하나를 더합니다. 접속 · 계정 · 비밀은 코어가 하고, 새 기능은 프리셋과 출력만 맡습니다.

명령은 프리셋만

화면은 프리셋 번호와 값(서비스 이름 · 경로)만 보냅니다. 실제 명령 글자는 서버 코드에만 있고, 실행 전에 화면에 그대로 보여 줍니다.

읽기 전용 · 출력은 저장하지 않는다

서버 상태를 바꾸는 명령은 넣지 않습니다. 출력은 포탈 메모리에 마지막 실행 한 건만 두고, 감사 로그에는 출력을 싣지 않습니다.

배치 — 세 가지 안

안좋은 점걸리는 점
A · 서버 정보에 탭으로화면이 늘지 않음서버 정보는 해석한 값만 보관한다는 규칙에 원문 출력이 섞임 · 계정의 허용 기능을 따로 켤 수 없음
B · 별도 특수 기능 권장계정마다 ‘서버 명령’ 을 따로 켬 · 출력 규칙이 섞이지 않음 · 일괄 틀은 공용으로 뽑아 둘이 씀화면 하나가 늘어남
C · 원격 명령 에이전트에 합침명령 화면이 하나로 모임에이전트 경유라 그 법인에서 켜야 함 — 에이전트가 없는 곳의 서버에는 길이 없음 · 통합 계정과 계층 계정 두 체계가 섞임

명령에 값이 들어가는 길 — 여섯 겹

1화면은 프리셋 번호와 값만 보냅니다. 명령 글자를 보내는 칸이 없습니다.
2프리셋 번호는 서버 코드의 목록에 있는 것만 받습니다.
3값은 종류별 허용 글자만 — 공백 · 따옴표 · $ ; | · 줄바꿈이 들어갈 수 없고, - 로 시작할 수 없습니다(② 의 값 종류 표).
4그래도 작은따옴표로 감싸고 -- 뒤에 둡니다.
5코어에는 완성된 문자열만 넘깁니다. 코어는 글자를 이어 붙이지 않습니다(지금 그대로).
6Linux 명령은 timeout 으로 감쌉니다 — 포탈 시한이 지나도 서버에 프로세스가 남지 않게.

붙지 않는 경우 · 실패했을 때

경우하는 일화면에 보이는 것
엣지가 수집하는 서버중앙은 붙지 않는다‘엣지 ○○ 포탈의 같은 화면에서 실행’ · 고를 수 없음
수집을 끈 서버붙지 않는다‘수집 끔’ · 고를 수 없음
계정이 없거나 승인 대기붙지 않는다(빈 비밀번호로 시도하지 않는다)‘계정 없음’ · ‘승인 대기’
계정에 ‘서버 명령’ 이 꺼져 있음붙지 않는다(④ 의 D8)‘이 계정은 서버 명령에 쓰지 않음’ — 설정 › 서버 접속에서 켠다
계정이 멈춰 있음붙지 않는다(앞선 로그인 거부로 멈춘 계정)‘계정 정지’
프리셋에 그 OS 묶음이 없음붙지 않는다‘이 프리셋은 Windows 에 없음’
로그인 거부다시 시도하지 않는다 · 공통 계정이면 계정 단위로 멈춘다(지금 규칙)‘로그인 거부’

출력 상한자르고 표시한다‘잘림’
