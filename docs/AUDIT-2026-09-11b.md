# 전체 소스 감사(2차) — 2026-09-11 (v2.478.0 기준 → v2.479.0 조치)

요청: "버그·보안 취약점·개선·튜닝 각 10개 이상". 대상: `server/src`(73.8천 줄) · `web/src`(45.2천 줄) · `pyportal`(9.2천 줄).
방법: 영역별 읽기 전용 분석 에이전트 4개(보안 / 서버 코어 / 서버 도메인 / 웹 — 각 11~12분, 결과를 파일로도 저장) + 직접
안티패턴 전수 grep(무가드 setInterval·비원자 쓰기·예외 삼킴·`split(':')`·ts 인덱스·무제한 Promise.all·무상한 파라미터·
NUL 바이트·pyportal 락/원자성) + **높음 등급·상충 항목은 파일을 열어 직접 재검증**. 실행/부하 측정은 하지 않았고
ms 수치는 코드 기반 추정이다. 직전 두 감사(09-09·09-11) 항목과 08-29 '버그 아님'은 제외했다.

정직 기록:
- v2.478 에서 "S5 조치"라고 쓴 `/tools/*` 조회 권한 게이트는 **4개 파일(34 라우트)만** 고친 부분 수정이었다. 6개 파일 42개
  라우트가 남아 있었고(S-4) 이번에 전부 닫았다(잔여 0 — `grep` 으로 확인).
- v2.478 문서의 "S13(ad.js NUL 바이트) 수정됨" 판정은 **틀렸다**. `grep -cP '\x00'` 이 0 을 돌려줬지만 `tr -cd '\000' | wc -c`
  로는 1바이트가 남아 있었다(`file` 이 'data' 로 분류한 이유). 이번에 이스케이프로 치환했고, 같은 클래스가 `guestdisk/db.js` 에
  2바이트 있었다. 탐지 방법을 CLAUDE.md 에 기록했다.
- 직접 탐색에서 올렸던 "alerts 틱 재진입 가드 없음" 은 재검증 결과 **오판**(notify 가 fire-and-forget 이라 틱이 겹치지 않음)
  — 철회하고 역기록에 남긴다. 코어 에이전트의 "guestdisk NUL 없음" 판정도 오판이었다(위).
- 코어 에이전트는 시간 상한으로 `routes/api|admin` 대부분·`auth/`·`health/`·`inventory/`·`toolcats/`·`upgrade/` 를 완독하지
  못했다. 그 디렉터리에 미발견 결함이 없다는 뜻이 아니다.

상태 표기: ✅ v2.479.0 조치 · ⏳ 보류(백로그, 사유 기록) · 확신도 C=CONFIRMED(문맥·호출부 확인) / P=PLAUSIBLE(추정 포함).
