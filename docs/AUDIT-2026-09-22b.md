## A. 확정 조치 (3건)

### SEC-01 — CSP 기본 켜짐 (가정을 측정으로 뒤집었다)

v2.576 까지 `index.js:137` 주석이 이렇게 적고 있었다:

> `// CSP는 인라인 스타일/intro 페이지 호환 이슈로 기본 비활성(CSP env로 옵트인 지정 가능).`

**이것은 측정하지 않은 가정이었다.** 실제로 걸어서 Chromium 으로 재 보니:

| 대상 | CSP 위반 |
|---|---|
| 메인 포탈 **21화면**(대시보드·VM·호스트·DS·알람·Explore·NSX·IPAM·원격·특수기능 6종·V4 3종·설정 2종) | **0건** |
| `/intro/index.html`·`/intro/light.html` | 위반 전부 — ① 외부 CDN 스타일시트 2종(jsdelivr Pretendard · Google Fonts IBM Plex Mono) ② `dc-runtime` 의 문자열 `eval`(`EvalError: Refused to evaluate a string`) |

즉 주석이 묶어 놓은 두 문제 중 **'인라인 스타일' 은 `style-src 'unsafe-inline'` 하나로 끝나고**
(React 의 `style={{}}` 은 스타일 속성이지 스크립트가 아니다) **'intro 호환' 만 실재**했다.
그래서 **앱 전체에 엄격 CSP**(`script-src 'self'` — `unsafe-inline`·`unsafe-eval` 없음)를 걸고
**`/intro` 에만** 완화 정책을 준다.

**왜 중요한가**: 세션 토큰이 `localStorage` 에 있어 **XSS 한 번이면 그대로 탈취**된다
(v2.538 이 그 한계를 기록해 두었다). CSP 가 없으면 그 위험에 **완화 수단이 하나도 없었다.**

`/intro` 완화가 안전한 이유: 실데이터·API 와 분리된 셀프부트 정적 데모이고(index.js 마운트 주석)
**세션 토큰이 없다**. v2.577 확인 — 사설 IP 0건 · 법인 문자열 0건 · vCenter 이름 0건.

⚠ **A/B 로 회귀 0을 확정했다** — `CSP=off` 와 켠 상태의 콘솔 오류가 **21건으로 동일**했다.
남은 오류는 이 컨테이너의 egress 정책이 외부 CDN 을 막아서 생기는 **기존 현상**이고 CSP 가
만든 것이 아니다. 탈출구(`CSP=off`·`CSP=<정책>`)는 그대로 유지한다.

⚠ **정직 기록**: `/intro` 는 **외부 CDN 에 의존한다**(jsdelivr · Google Fonts). 폐쇄망에서는 그
글꼴이 안 받아지고(기능은 동작), 공급망 관점에서는 **공개 페이지의 외부 의존**이다. 없애려면
글꼴을 번들해야 하고 그것은 별건이다.

### PERF-01 — `/top` 이 상시 폴링 경로인데 캐시가 없었다

`web/src/views/Explore.jsx:59` 가 **15초마다** 부르는데, 형제 인벤토리 5종
(`/summary`·`/hosts`·`/vms`·`/datastores`·`/alarms`)과 달리 `memoJson` 이 없어
**매 요청 VM 배열 5회·호스트 3회를 복사해 정렬**했다.

운영 규모 실측(**MOCK_SCALE=3 · 33 vCenter · 558 호스트 · 6,004 VM**):

| | 콜드 | 웜 | 콜드/웜 |
|---|---|---|---|
| `/vms?limit=5000` | 88.6ms | 23.7ms | 3.7x |
| `/tools/thin-vms` | 19.9ms | 3.8ms | 5.2x |
| `/summary` | 7.7ms | 1.4ms | 5.5x |
| **`/top`** | **14.5ms** | **14.1ms** | **1.0x ← 캐시 없음이 그대로 드러난다** |

수정 후 `/top` p50 **14.1ms → 3.0ms**. 동시 20요청 벽시계 **28ms**(예전이면 20회 전량 정렬).
응답 계약은 그대로(키·건수 동일 확인).

⚠ **정직 기록 — 이득의 성격**: `memoJson` 의 TTL 은 12초이고 화면 폴링은 15초라
**단일 사용자 단독 폴링에는 이득이 없다**(매번 미스). 이득은 ① **동시 사용자·탭**(N명이 1회 계산을
공유) ② **연속 재렌더·버스트**(single-flight 합류)다. 형제 5종과 **정확히 같은 성질**이다.

⚠ `extraKey: scopeKey(...)` 는 **필수**다 — 없으면 무제한 계정 결과가 범위 계정에 캐시로 샌다
(v2.255~2.257 규약. `/summary`·`/overview` 에서 실제로 겪은 사고다).

### SEC-02 — 압축 해제 출력 상한 (형제 경로 누락, **잠재**)

`upgrade/archive.js:66,106` 은 v2.488(L-1)에 `maxOutputLength` 를 받았는데
`backup/service.js` 의 `gunzipSync` **2곳**은 빠져 있었다.
실증: **100KB gzip → 100MB(증폭 1,029배)**, 상한을 걸면 `ERR_BUFFER_TOO_LARGE` 로 즉시 차단.

⚠ **정직 기록 — 지금 도달 가능한 취약점이 아니다.** `parseUploadedArchive` 를 부르는 라우트는
**없고**(전수 확인) `readBackup` 은 우리가 만든 파일을 읽는다. 그래도 막는 이유는 이름이
'Uploaded' 이고 업로드 라우트를 붙이는 순간 상한 없는 경로가 되기 때문이다. 🟢 **잠재**로 분류한다.

### IMP-01 — `MOCK_SCALE` — 운영 규모를 잴 수 있게 됐다

## D. 훑었고 **결함 없음**으로 확인한 보안 축

| 축 | 확인 방법 | 결과 |
|---|---|---|
| XSS / DOM 주입 | `dangerouslySetInnerHTML`·`innerHTML` 전수 | 앱 코드 **0건**(히트는 vendored react-dom 내부와 `/intro` 의 생성 런타임뿐) |
| 감사 로그 주입 | `audit.js` 기록 경로 | `JSON.stringify(obj)+'\n'` 이라 개행이 **이스케이프**된다 → NDJSON 주입 불가 |

| 경로 탈출 | `res.download`·`sendFile`·`path.join(req.*)` 전수 | `backupPath` → `safeName()`, `dlsource.findFile` → `SAFE_RE=/^[\w.+-]+\.(tar\.gz|zip)$/`(`/` 불가) |
| zip slip | `parseUploadedArchive` | 파일 전개 없음(gunzip+JSON.parse) |
| 토큰 비교 | 수집·중앙·API 키 | 전부 `tokenMatches`/`timingSafeEqual`. 느슨한 `===` 비교 **0건** |
| XFF 스푸핑 | `trust proxy` | `TRUST_PROXY` env 가 있을 때만 `req.ip`, 기본은 실제 peer |
| 열린 리다이렉트 | `res.redirect(` 전수 | **0건** |
| 보안 헤더 | 실제 응답 확인 | `X-Content-Type-Options`·`X-Frame-Options: DENY`·`Referrer-Policy`·`X-Permitted-Cross-Domain-Policies` 있음, `X-Powered-By` 없음, HSTS 는 **https 일 때만**(올바름) |
| 대량 할당 | `PATCH /users/:username` | `adminOnly` |
| 레이트리밋 커버리지 | 전역 미들웨어 skip 조건 | `/api` 전체 적용(health·metrics·`/dl`·정적만 제외) |

⚠ **HSTS 를 기본으로 켜지 않은 이유**(정직 기록): 이 현장은 IP 주소 + 자체서명 인증서 접속이
흔한데 HSTS 는 그 도메인의 http 접속을 **영구히** 막는다. 되돌리기 어려운 방향이라 현재의
'실제 https 일 때만' 조건을 유지했다.

## F. 이번에 내가 한 실수 (기록)

회귀 테스트 초판에서 `zlib.gunzipSync\([^)]*\)` 를 썼다가 `gunzipSync(fs.readFileSync(p), {...})`
의 **첫 `)` 에서 잘려** 상한이 있는 호출을 '없다' 고 오판했다. CLAUDE.md v2.535 가
`chmodSync(FILE(), 0o600)` 로 **똑같은 실수**를 기록해 둔 항목이다. 괄호 깊이 파서로 교체했고,
그 사실을 테스트 주석에 적었다.
