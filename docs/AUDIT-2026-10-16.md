## 동작 변화(운영자가 알아야 할 것)

- iDRAC 스캔 '교체' 모드는 그 엔트리 범위만 지운다(등록 항목에 `scanRangeId`).
- 업그레이드 전 오프라인 설치본: root 확인이 서비스 계정 소유 호스트 키 파일의 회수를 적용하고, 그 파일이 손상이면 멈춘다(fatal).
- 아이실론 '지금 수집' 대기열은 `scan-journal.json` 에 남아 재시작 뒤 돌아온다 · 자동 업그레이드는 진행 중인 에이전트 대량 배포를 기다린다(상한 그대로).
- 중앙의 지속형 503 에 `Retry-After: 60` — 그 503 을 받는 엣지 호출은 재시도마다 30~45초 기다린다.
- 주문형 vCenter 작업은 비활성·점검중·엣지 위임·인증 정지 vCenter 에 로그인하지 않고 409 와 사유를 준다(게스트 계정 추가만 인증 정지에도 1회 시도).
- 클러스터 점검 CSV 에 '데이터센터'·'클러스터 ref' 2열 · 라이선스 조회 실패는 `[]` 가 아니라 null + 사유.
- 끊긴 ESXi 호스트의 온도는 적재·집계에서 빠진다 · 유령 스냅샷 후보는 `consolidationNeeded` 근거가 있을 때만 경고(그 밖은 정보, 알림 제외).
- 네트워크 로그 분석의 건수는 상한 100,000(`ISSUE_COUNT_CAP`), 엣지 연합 조회(검색어·심각도)는 10,000(`COUNT_CAP`)까지 — 넘으면 'N건 이상'(v2.743 LEFT-04 정정 — 처음에는 둘 다 100,000 으로 적었다).
- SAN: 빈 슬롯을 장애로 세지 않는다 · peer zone 속성 멤버를 그림에서 뺀다 · 수집 주기 2시간 이상도 처리량을 계산한다.
- 네트워크 트래픽 분석 카드는 관리자 표시(서버 권한 무변경).
