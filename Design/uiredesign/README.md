## 색·치수의 출처

전부 `web/src/version_4/v4.css`(v2.508 승격 전 이름 `version_3/v3.css`)에서 **그대로 lift** 했다
(반올림 금지). 값을 바꿀 일이 생기면 v4.css 를 먼저 보고, 시안과 구현이 갈라지지 않게 양쪽을
같이 고친다. 클래스 접두는 승격 후에도 `v3-` 를 유지했다 — 이름만 낡았고 값은 현재 토큰이다.

배경 `#f4f6f9` · 패널 `#ffffff` · 보더 `#dfe4ec` · 표머리 `#f0f3f7` · 행구분 `#e6eaf0` ·
막대트랙 `#e8ecf2` · 본문 `#1a2130` · 보조 `#526075` / `#68738a` · 강조 `#2563eb` / `#0e7490` ·
활성메뉴 `rgba(59,130,246,.85)` · 상태 빨강 `#dc2626` · 주황 `#b45309`(텍스트) `#d97706`(막대) ·
초록 `#15803d`(텍스트) `#16a34a`(막대). 사이드바 236px · 본문 13px/1.4 · 제목 22px/700 ·
KPI 24px/800 · 표 12px · th 모노 9.5px 대문자 · 패널 radius 12px · **그림자 없음(플랫)**.

임계값은 `consoleData.js` 의 `WARN_PCT 75` / `CRIT_PCT 90` 과 같다 — 시안 임의값을 쓰지 않는다.

## 정직 규칙 (시안에서 지킨 것)

수집 API 가 없는 것은 그리지 않았다 — **계약 전력 대비 %** · **사이트 간 백본 회선** ·
**펌웨어 기준선 준수율** · **SLA/가용률** · **자원의 금액 환산**. 원래 아트보드
(`../통합 관제 콘솔 UI 핸드오프(20260912).zip`)에는 이 값들이 있지만 `V3App.jsx:5-7` 이
"수집 API 없음"이라 적어 둔 항목이다.

인시던트 발생 추이는 `/insights/incidents.byDay` 로 그릴 수 있으나 **인메모리**
(`alerts.js:333`, 재시작 시 소실) · 최근 100건 · **발생만**(해소 미집계) · 알림 엔진 발화
기준이다. 그래서 '알람 추세'가 아니라 그 제약을 붙인 이름으로 표기했다.

## 씨딩(재생성)

게시본 `vmware-portal-ui-redesign.html`(2.6MB)은 **에디터 런타임이 통째로 든 파생물**이라
커밋하지 않는다(`.gitignore`). 고칠 때는 이 디렉터리의 `.dc.html` / `canvas.json` 을 고치고
Claude Code 에서 `/design` 으로 다시 씨딩·게시한다. 같은 파일 경로로 다시 게시하면 URL 이
유지된다.

## 구현 상태 (v2.508)

이 시안은 **V4 신규 포탈로 구현됐다** — `web/src/version_4/` · 설정 › 신규 포탈 보기 › **V4**.
시안과 구현이 갈라진 곳은 구현 쪽이 맞다. 지금까지 정정한 것:

| 시안 초안 | 정정 | 이유 |
|---|---|---|
| 모드가 '호출 API' 도 바꾸지 않는다 | 호출 API 집합은 **다를 수 있다** | ②와 ⑤는 패널이 달라 실제로 다른 API 를 부른다. 보장하는 것은 권한·데이터 범위·임계값이다 |
| viewer → 경영(잠긴 벽 회피) | 근거만 유지, **'다 보인다' 는 뜻은 아님** | 경영 랜딩의 `/tools/*` 패널도 viewer 에게는 똑같이 잠긴다 |
| 클러스터 여력 'N+1 기준' | **현재 스냅샷의 할당/용량 비율** | `/tools/capacity` 에 N+1 판정 필드가 없다 |
| IA 트리 79+14+**6** | 79+14+**9** | V4 화면이 6개에서 9개로 늘었다(법인 비교·전력·기능 찾기 추가) |

선행 수정 3건(F0-1 사용빈도 상한 12→200 · F0-2 카드 JSX 중복 · F0-3 '76개' 낡은 주석)은
v2.508 에 모두 반영했다.
